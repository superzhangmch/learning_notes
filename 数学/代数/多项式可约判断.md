按"对随机 10 次、|系数|<100 的多项式,该方法能给出确定结论的概率"统一成 0~1:

```
┌───────────────────┬───────────┬───────────────────────────────────────────────────────────────────────────────────────────┐
│       方法         │  命中率   │                                                 说明                                       │
├───────────────────┼───────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
│ 有理根定理         │ ≈ 0.011   │ 21/2000 实测。只对"恰好可约"的那部分有输出,对不可约输入恒为 0(证不了不可约)                          │
├───────────────────┼───────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
│ Eisenstein        │ ≈ 0.000   │ 0/295 实测(95% 置信上界约 0.010)。随机输入下基本永不开口                                         │
├───────────────────┼───────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
│ mod p,试 1 个素数  │ ≈ 0.092   │ 实测(平均第 10.9 个素数命中的倒数),理论值 1/10 = 0.100(S₁₀ 中 10-循环占比)                        │
├───────────────────┼───────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
│ mod p,试 k 个素数  │ 1 − 0.9^k │ k=7 → 0.52,k=22 → 0.90,k=44 → 0.99                                                         │
├───────────────────┼───────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
│ mod p,不限素数     │ ≈ 1.000⁻  │ 实测 295/295。差的那一点是"群无 n-循环"的多项式(如 x⁴+1),它们命中率严格 = 0,但在随机样本中测度趋于 0  │
├───────────────────┼───────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
│ LLL(van Hoeij)    │ 1.000     │ 完备算法,恒有确定输出                                                                         │
└───────────────────┴───────────┴────────────────────────────────────────────────────────────────────────────────────────────┘
```
也就是, 有理根定理和Eisenstein, 基本不能打.
