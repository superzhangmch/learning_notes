# 环(ring) 的理想 (Ideal) 

### 为什么会有理想？——历史动机

数学家发现某些数环里唯一分解会失败：6 = 2 × 3 = (1+√-5)(1-√-5). {2, 3, 1±√-5} 看起来都不可再分，但分解不唯一——说明这些元素**还不够细**，内部藏着结构。
- 库默尔的想法：虚构一些"理想数"，让分解重新唯一。但这些数不真实存在。
- 戴德金的转化：与其找不存在的数，不如研究它**留下的痕迹**——它能整除哪些元素，这个集合是真实的。

> 理想 = 虚构元素的影子，用集合代替了不存在的数。

### 什么是环的理想

**定义**

I ⊆ R 是理想，需要满足：
- I 是加法子群（含零，含逆，加法封闭）
- **吸收性**：r ∈ R, a ∈ I ⇒ ra ∈ I.

吸附是灵魂所在: 任何环里的元素乘进来，都逃不出 I。加法子群条件只是让 I 能在环里站稳脚跟的基础设施。

**理想的本质是乘法概念**

理想的核心应用全是乘法的事：

- **唯一分解**：$I = 𝔭₁^{e₁}𝔭₂^{e₂}⋯𝔭ₖ^{eₖ}$，理想之间的乘法
- **素理想**：ab ∈ 𝔭 ⇒ a ∈ 𝔭 或 b ∈ 𝔭，乘法性质
- **吸收性本身**：ra ∈ I，乘法

加法条件是环境要求，乘法条件才是理想的本质。

**理想不一定是环**

如果ring定义成可以没有单位元, 则ideal 是ring. 或者说, ideal 是没有单位元的ring. ideal 可以有单位元, 只是不一定一定有.

**主理想**

| | 定义 | 例子 |
|--|------|------|
| 主理想 | (a) = {ra | r ∈ R}，单个元素生成 | (2) := {2r | r ∈ ℤ[√(-5)]} ⊆ ℤ[√(-5)] |
| 非主理想 | 需要至少两个生成元 | 𝔭 = (2, 1+√(-5)) := {2r + (1+√(-5))s | r, s ∈ ℤ[√(-5)]} |

**素理想**

- 在一个交换环 R 中，一个真理想 P ≠ R 称为素理想，如果：对任意 a, b ∈ R，若 ab ∈ P，则 a ∈ P 或 b ∈ P。
  - 直接从素数的整除性质抽象而来：p|ab ⇒ p|a 或 p|b。素理想是理想唯一分解的**原子**——无法被更细的理想绕过。
- 非交换环里也有“素理想”，但定义要更小心，因为乘法不交换。通常默认讨论的是双边理想 P ⊊ R。
  - 一个双边理想 P 称为素理想，如果对任意双边理想 A, B：若 AB ⊆ P，则 A ⊆ P 或 B ⊆ P。这里 AB 指由所有有限和 ∑ aᵢbᵢ 生成的理想。
  - 等价地，也常写成：若 aRb ⊆ P，则 a ∈ P 或 b ∈ P。其中 aRb = {arb : r ∈ R}。

### 两个完全相反的用途: 让环扩大与缩小

- 理想作为"虚拟元素的影子"  →  局部化/扩环  →  ring 变大. 理想告诉你沿哪个方向扩张，局部化把"除法"真正实现出来
- 理想作为商环的 kernel    →  商环        →  ring 变小. 把理想里所有元素强行认同为零，折叠环的结构

### 理想能让的环的乘法分解, 具有唯一性

环里元素的唯一分解未必成立. 

看 ℤ[√(-5)] = {a + b√(-5) | a, b ∈ ℤ} 中例子：6 = 2 × 3 = (1+√-5)(1-√-5), 它可以分解但分解不唯一. 2, 3, 1±√-5 看起来都不可再分，其实在更大的环里(或者说如果原ring增添一些元素), 是可以再分解的: 令 2=p², 3=qq̄, (1+√-5)=pq, (1-√-5)=pq̄, 可以解出 p/q/q̄, 并得到 6=p²qq̄. 这时候, 6 得到了唯一分解. 原环里不只是 6 没有唯一分解, 所以需要添加的可能不只是 p/q/q̄ 三个.

如下构造 ℤ[√(-5)] 的理想
- 𝔭 := (2, 1+√(-5)) = {2r + (1+√(-5))s | r, s ∈ ℤ[√(-5)]}
- 𝔮 := (3, 1+√(-5)) = {3r + (1+√(-5))s | r, s ∈ ℤ[√(-5)]}
- 𝔮̄ := (3, 1-√(-5)) = {3r + (1-√(-5))s | r, s ∈ ℤ[√(-5)]}
- (2) := {2r | r ∈ ℤ[√(-5)]}, 乃主理想. 上面三个都不是主理想(不能由一个元生成)

然后在理想集上定义的乘法(𝔞𝔟 = {∑ᵢ aᵢbᵢ | aᵢ ∈ 𝔞, bᵢ ∈ 𝔟}, 为有限项求和; 乃通用操作)上有 

```
(2) = 𝔭²
(3) = 𝔮𝔮̄
(1+√(-5)) = 𝔭𝔮
(1-√(-5)) = 𝔭𝔮̄
(6) = 𝔭²𝔮𝔮̄
```

也就是, 原 ℤ[√(-5)] 中元素未必可以唯一分解. 但是把主理想集合 (x):={xr|r∈ℤ[√(-5)]}, 再扩充一些非理想, 在理想集合的乘积上, 6 的唯一分解就成立了.

所以, 所谓理想让唯一分解成行
- 指的是理想当作元素来说的.
- 有了理想, 能搞唯一分解, 其实就是能把主理想来给分解.
- 理想与唯一分解有关, 并不是某一个理想导致所有元素都可以唯一分解, 而是一个理想只能解决一部分元素的分解. 

另外:
- 不是所有 ring 的理想集合都有唯一分解性(满足这样的叫戴德金ring; ℤ[√(-5)] 正属于此). 
- 对于 PID=每个理想都是主理想的整环, 在ring内就可以唯一分解, 不需要跑到理想空间.

note: 
```
唯一分解失败
    ├─  戴德金的路：不动环，换语言，用理想分解  ← 理想的套路
    └─  库默尔的路：扩环，造出新元素          ← 不是理想的套路
```

一个有点反直觉的地方: 原 ring 内不能唯一分解, 在于缺一些元素, 通过理想的方式搞定了唯一分解, 约等于说把缺的元素补上了. 那么这个理想集合的势, 一定是大于原ring元素个数的. 实际上不一定. 对于戴德金环，每个理想由**至多两个元素**生成，所以 |I| ≤ |R × R| = |R|², 对于 R = ℤ[√(-5)]，|R|=ℵ₀，故|I| ≤ ℵ₀² = ℵ₀ = |R|, 两者**等势**。

### 理想为什么能定义等价关系, 并构造商环与同态？

**(1). 只需是加法子群, 就能定义等价关系**

理想 I 定义：a ∼ b ⇔ a - b ∈ I. 这用的只是 I 的**加法子群**部分，加法子群的三个条件恰好对应等价关系的三个条件：

| 加法子群 | 等价关系 |
|---------|---------|
| 含零元：0 ∈ I | 自反性：a ∼ a |
| 含逆元：a ∈ I ⇒ -a ∈ I | 对称性：a ∼ b ⇒ b ∼ a |
| 加法封闭：a,b ∈ I ⇒ a+b ∈ I | 传递性：a∼ b, b∼ c ⇒ a∼ c |

> 加法子群和等价关系，是同一个结构的两种语言。

**(2). 只有理想这样的加法子群定义的等价关系, 才可以构造商环**

为什么不是所有加法子群都能造商环，只有理想可以？ 有了等价关系，商群（加法）是自动的。但商环还需要乘法有良定义：

[a] ⋅ [b] = [ab]

换代表元结果要不变：a' ∼ a 时，需要 [a'b] = [ab]，即 a'b - ab = (a'-a)b ∈ I。

> 吸收性不是随便加的条件，它精确地是"让商环乘法良定义"所需要的最小要求。

**(3). 理想与商环的关系**

理想 I 对应商环 R/I，本质是**把 I 压成零**：π: R ↠ R/I, r ↦ r + I; π 是环同态，ker π = I。反过来，**任何环同态的 kernel 都是理想**。

所以：理想 ⇔ 某个环同态的 kernel. 理想之于环, 正如正规子群之于群.

注意: field 域, 不再有类似理想/正规子群的对应物. 因为域之间的非零同态必然是单射. 没有非平凡的同态与 kernel. 如果field 有类似理想的东西, 那么这个东西, 会是field 作为环的理想. 这个理想不会是非平凡的: 设 I 是域 F 的理想，0 ≠ a ∈ I，则 a⁻¹ ∈ F，由吸收性： a⁻¹ ⋅ a = 1 ∈ I ⇒ ∀ r ∈ F, r ⋅ 1 = r ∈ I ⇒ I = F. 域里每个非零元都可逆，任何非零理想立刻吸收整个域。

### 唯一分解与商环的关系

理想的唯一分解是商环结构的完整说明书：

$$R/I ≅ R/𝔭₁^{e₁} × ⋯ × R/𝔭ₖ^{eₖ}$$

| 分解的信息 | 商环的信息 |
|-----------|-----------|
| 有哪些素理想 | 直积有几个分量 |
| 幂次 eᵢ | 每个分量里幂零元的深度 |
| 分解唯一 | 商环结构唯一确定 |

幂次 e=1 时 R/𝔭 是整环，最干净；幂次越高，商环里幂零元越"厚"。
