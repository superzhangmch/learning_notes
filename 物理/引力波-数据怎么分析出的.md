接收器收到的数据是 1维的时间序列数据: 长度的变化率(10⁻¹⁹这么小). 正是要从这个序列数据中发现引力波.

以第一次测出引力波的那份数据(32s), 来做一个简化的引力波的发现: 

1. 获得全局的频率-强度图: 原数据按4s间隔(可重叠), 弄成 N 个小块, 每个小块上做fourier 分解, 得到这个小块上的频率-波幅图. 对于每个频率, 可以得到 N 个小块的 fourier 分解的该频率的系数数组, 然后得到该频率的全局强度
2. 全局32秒波形whiten: 对 32s 做fourier, 对每个频率的系数根据前一步的“频率-强度”关系, 做系数调整, 调整完做逆 fourier 变化.
3. 波形对比: 对相隔3000km 的两个设备上的数据, 都做上面操作, 然后做波形匹配: 具体是固定一个, 让另一个滑动扫瞄. 每一停留位置都算相关性计算. 然后相关度最大的地方, 就是波形最匹配的的地方. 然后看两个波形的时间偏移: 需要 “光速 x 偏移 < 两地距离”. 这里测得是 7.3ms(比官方的 6.9ms 大一些)
4. 以上两个设备就能印证了有引力波出现. 然后是估计多大质量的黑洞导致.
  - 对于每条 whitten 曲线, 可以弄出频谱图, 可以看到频炉的热点区域. 然后扫描不同的黑洞质量, 用相对论算出引力波并获得相应波的频率, 和实际的波频谱对比: 最接近的就是背后的实际黑洞质量.
