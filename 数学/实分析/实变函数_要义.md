## 实变函数 / Lebesgue 积分

实变函数课程的主要内容, 就是先严格定义“长度/面积/体积”，再在这个基础上定义积分。Lebesgue 的核心不是“怎么算面积”，而是先回答：什么东西配叫有面积？面积该怎么定义？

### 可测 VS Lebesgue可积

- 可测：面积这个概念能不能谈。
- 可积：面积不但能谈，而且有限。
  * 对非负函数 f ≥ 0：f Lebesgue可积 ⟺ 图像下方区域可测且面积有限(∫f < ∞)
  * 对一般函数 f Lebesgue可积 ⟺ ∫|f| < ∞, 也就是正负两边的总面积有限，不能靠抵消。∫f = 正体积-负体积, 但前提是别出现：∞-∞, 所以要求 ∫ |f| < ∞

### Fubini / Tonelli 定理

一句话：如果真的是同一个可测体积，那么横着切、竖着切，结果都一样。

- Tonelli 定理: 若 f ≥ 0, 则可以交换积分顺序，结果允许是 ∞。
- Fubini 定理: 若 ∫∫ |f| < ∞, 则可以交换积分顺序，而且结果有限。

### 为什么黎曼/广义黎曼积分换序麻烦？

因为广义黎曼积分本质上是“有限区间积分的极限”。

比如 ∫₀^∞ f(x) dx = lim_{A→∞}∫_0^A f(x) dx 它依赖极限过程。二重积分换序，本质上可能就是：换了一种取极限的顺序或路径。如果不是绝对收敛，就可能结果不同。

 最核心区别

| 观点 | 黎曼/广义黎曼 | Lebesgue |
|---|---|---|
| 本质 | 局部积分后取极限 | 先定义整体测度 |
| 无穷区间 | 依赖极限过程 | 直接在整体空间上积分 |
| 换序问题 | 可能依赖顺序 | 非负或绝对可积则安全 |
| 核心条件 | 极限是否存在 | 面积/体积是否可测且有限 |
