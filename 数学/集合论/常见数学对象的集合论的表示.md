
# 集合论：空集 -> 数学宇宙

一般说, 集合论是数学的基础. 然后人们就在一种感性认识上开始用集合. 

其实从严格数学角度, 说集合论是数学的基础, 是说数学研究对象真的是可以从集合论的公理出发构造的. 而集合论公理里, 构造集合的最最基础的原料其实是空集 ∅. 像是无生万物了.  

> 数学只需要一种对象（集合），一种关系（∈），几条公理。
> 从空集出发，用括号的嵌套，生长出整个数学宇宙。

∅ → {∅} → {∅,{∅}} → ⋯ → 万物

## 一、自然数

冯·诺依曼构造：**用集合的层级表示数的大小**

- 0 = ∅
- 1 = {∅}
- 2 = {∅, {∅}}
- n+1 = n ∪ {n}

每个自然数 n 就是集合 {0,1,2,…,n-1}，无穷公理保证 ℕ 整体存在。

## 二、整数、有理数、实数

核心手法：**等价类**

| 数系 | 构造 | 直觉 |
|------|------|------|
| ℤ | (ℕ×ℕ)/∼，(a,b)∼(c,d)⇔ a+d=b+c | (a,b) 表示 a-b |
| ℚ | $(ℤ×ℤ^*)/∼$，(a,b)∼(c,d)⇔ ad=bc | (a,b) 表示 a/b |
| ℝ | 戴德金分割：r = {q∈ℚ| q < r} | 实数就是它左边所有有理数的集合 |
| ℂ | ℝ×ℝ，或 ℝ[x]/(x²+1) | (a,b) 表示 a+bi |

关键细节：
- 2/3 = {(2,3),(4,6),(6,9),…} 是一个**无穷集合**
- π = {q∈ℚ| q < 3.14159…} 也是一个**无穷集合**
- a < b ⇔ a ⊊ b，大小比较就是集合包含

## 三、有序对与函数

- **有序对**（Kuratowski）： (a,b) = {{a},{a,b}}
- **函数**不是规则，是有序对的集合：f:A→ B = {(a,b)| a∈ A, b∈ B} 满足单值性

f(x)=x² 在 ℕ 上 = {(0,0),(1,1),(2,4),(3,9),…}

> 大多数函数没有公式，但作为集合它们存在。

## 四、代数结构

- 群 = 集合 + 一种运算（结合律、单位元、逆元）
- 环 = 集合 + 两种运算（加法交换群 + 乘法幺半群 + 分配律）
- 域 = 环 + 乘法可逆

层级：**群 ⊂ 环 ⊂ 域**

有限域：𝔽ₚ = ℤ/pℤ，p 为素数，每个非零元都有逆元。

## 五、多项式

**多项式 = 系数的有限序列（几乎处处为零的函数 ℕ→ R）**

3x²+2x+1 ⟷ [1,2,3] ⟷ {(0,1),(1,2),(2,3)}

x = (0,1,0,0,…) x²=(0,0,1,0,…)

运算：
- 加法：逐位相加
- 乘法：**卷积** cₖ = ∑ᵢ₊ⱼ₌ₖ aᵢ bⱼ

字母 x 只是占位符，提示"第几位配第几次幂"，本身没有神秘之处。

## 六、商环与扩域

用多项式模不可约多项式，**制造新的数**：

ℂ ≅ ℝ[x]/(x²+1) i = [x] 这个等价类
ℚ(√2) ≅ ℚ[x]/(x²-2)
$$𝔽_{pⁿ} ≅ 𝔽ₚ[x]/(f(x))$$

> i 不是凭空定义的神秘符号，就是序列 [0,1] 的等价类。

## 七、那些"显然存在"实际需要构造的东西

| 对象 | 实际上是 |
|------|---------|
| 负数 -3 | 等价类 [(0,3)] |
| 函数 f(x) | 有序对的集合 |
| 序关系 ≤ | 有序对的集合 |
| 数列 (aₙ) | 函数 ℕ→ℝ |
| 极限 | 关于集合的逻辑命题 |
| 同构 ≅ | 存在某个满足条件的集合 φ |
| 无穷大 ℵ₀ | ℕ 本身 |
| 概率 P(A) | 测度函数，有序对的集合 |
| 数学证明 | 符号序列，ℕ→Σ 的函数 |

## 八、构造全景

```
∅
│
├─▶ ℕ（冯·诺依曼序数）
│    └─▶ ℤ（等价类：差）
│         └─▶ ℚ（等价类：商）
│              └─▶ ℝ（戴德金分割）
│                   └─▶ ℂ（有序对 或 商环）
│
├─▶ 有序对 → 函数 → 关系 → 序
│
└─▶ 代数结构
      ├─▶ 群 → 环 → 域
      └─▶ R[x]（系数序列+卷积）
               └─▶ R[x]/(f)（商环，制造新数）
```

## 核心手法只有三个

| 手法 | 作用 |
|------|------|
| **后继** n∪{n} | 从无到有，构造自然数 |
| **等价类** | 构造整数、有理数、商环、商群 |
| **戴德金分割** | 填补有理数的"洞"，构造实数 |
