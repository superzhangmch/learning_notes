### {ℵᵢ} 正巧表示了所有无穷集合的 cardinality

一个集合:
- 有限集合, 势为 自然数集合 N 中某个数.
- 无限集合, 势必然为 ℵ₀=自然数个数, ℵ₁, ℵ.., ℵ_ω, ℵ_{ω+1}, .. 中某个之一.

所以, {1, 2, 3, ..., n, ..., ℵ₀, ℵ₁, .., ℵₙ, ℵₙ₊₁, .., ℵ_ω, ℵ_{ω+1} ...}, 乃集合的势的“集合”(其实, 它是一个 proper class，不是集合; 如果它是集合，它自身就有一个基数，这个基数必须大于其中所有基数，矛盾), 任何集合的势, 都能在其中找到对应. 
- ℵ₀: 自然数个数
- ℵ₁: 下一个集合大小(或元素个数/势/基数/cardinality). 不存在集合, 它的cardinality 是 ℵ₀, ℵ₁ 之间.
- ℵₙ, ℵₙ₊₁: 不存在集合, 它的cardinality 是 ℵₙ, ℵₙ₊₁ 之间

### 连续统假设

- 对实数 R, 他的势 |R| = 2^ℵ0 是否就是 ℵ_1, 这就是连续统假设(已被证明, 它是独立于 ZFC 的).
  - 2^{ℵ₀} 具体等于哪个 ℵ，在 ZFC 中是完全开放的：通过特别的构造, 可以是 ℵ₁（即 CH 成立）, 可以是 ℵ₂, ℵ_{ω₁}，甚至更大.
    - 唯一的约束：König 定理要求 cf(2^{ℵ₀}) > ℵ₀（即它的共尾度不能是可数的）. 这正是集合论最深刻、最令人着迷的地方之一。
- 广义连续统假设: 更一般的, 2^ℵₙ 是否是 ℵₙ₊₁?
  - ZFC 中，对任意 α，2^{ℵ_α} 等于哪个 ℵ 完全开放；GCH 公理则是一口气规定 2^{ℵ_α} = ℵ_{α+1} 来关闭所有这些自由度的额外公理。
    - GCH 是一条公理（一个命题），不是公理体系。加上它之后，公理体系是 ZFC + GCH。

### 序数和 ℵ

序数列是从0/1/2 开始无止境的一个不可数序列: 0,1,2,…, ω=ℵ₀, ω+1,…, ω²,…, ω^ω,… , ω^{ω^ω}, ... ω₁=ℵ₁, ..., ℵ₁+1,… ℵ₁+ω, ..., ℵ₂, …
- ℵ₀, ℵ₁, .., ℵₙ, ℵₙ₊₁, 也在其中. {ℵ} 不过是一些特殊的序数
- 超限归纳/超限递归定义的极限step 不只是发生在 ℵ 位置, 而是 ω, ω² 等, 没有上一个元素的地方, 都需要有超限limit 步骤
- 任意良序集合，都与唯一一个序数同构（这是序数的核心定理）。
  - 对于一个无穷良序集合, 它的良序, 正好对应全序数序列的某个前缀序列, 但是它的cardinality 只能是不大于最大序数的最近 ℵ
    - 或者说: 一个良序集合的序型（order type）是某个序数 α，而它的基数 |α| 是不超过 α 的最小 ℵ，即 α 所属的那个 ℵ 块。
- ℵₙ, ℵₙ₊₁之间有无穷多序数, 其中每个都可以对应某个集合的良序的最大序号, 但是这些中间序数背后的集合的 cardinal 只能是ℵₙ.
  - 也就是说, 序数列是绵延连续的, 其中的ℵ则是跳变的.

### 回到  ℵ 的定义

ℵ 源头上, 其实是靠良序/序数来定义出的. 

全序序列中的每个序号, 其实也是集合. 如果两个序号集合, 能够建立双射(则他们的 cardinality 一样), 则算等价. 于是可以建立等价类. 而每个 ℵ 其实就是对应的一类等价类(或者说是每个等价类中的一个代表元素 -- 等价类中元素在序号上是连着的, 而 ℵ 正是这个等价类中序号最小的那个).
- 更正式说: 同一等价类里的序数，在序数列上是一段连续的区间，左端点就是 ℵ（初始序数），右端点是下一个 ℵ 的前一个序数。

从这个角度 ℵ 确实对应了集合的cardinal.

但是 ℵ 是定义在良序/序数上的, 而集合并不一定有良序, 除非你承认 AC 选择公理(从而良序定理), 否则就会有集合的 cardinal 并不被 ℵ 覆盖. 有了选择公理后, 无穷集合的cardinal 一定是某个 ℵ.
