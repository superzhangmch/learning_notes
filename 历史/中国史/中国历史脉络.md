宋以前, 有两条 “正统线” 脉络: (1). 北魏到隋唐五代宋 (2). 汉魏晋南朝

## 北魏到隋唐五代宋：中原正统线

```text
北魏 → 西魏 → 北周 → 隋 → 唐 → 后梁 → 后唐 → 后晋 → 后汉 → 后周 → 宋
```

核心特点：

> 多是北方/中原军政集团内部重组、篡位、兵变、藩镇夺权。

典型交接：

- 北周 → 隋：杨坚篡北周
- 隋 → 唐：李渊逼隋禅让
- 唐 → 后梁：朱温逼唐禅让
- 五代内部：多为藩镇军阀互相消灭
- 后周 → 宋：赵匡胤陈桥兵变，后周禅让

### 五代十国关系

**五代**不包括在十国里。

```text
五代 = 后梁、后唐、后晋、后汉、后周
十国 = 吴、南唐、吴越、闽、楚、南汉、前蜀、后蜀、荆南、北汉
```

理解：

> 五代是中原正统线；  
> 十国是唐末地方藩镇割据形成的区域政权。

不是“五代 + 十国 = 11个”，而是：

```text
5 + 10 = 15个政权
```

###  北魏的上游

北魏不是中原王朝禅让来的，而是：

```text
拓跋鲜卑 → 代国 → 北魏
```

背景：

```text
西晋崩溃 → 五胡十六国 → 北魏统一北方
```

北魏后来汉化，成为隋唐北方政治传统的重要上游。

## 汉魏晋南朝：另一条正统线

```text
东汉 → 曹魏 → 西晋 → 东晋 → 刘宋 → 南齐 → 南梁 → 南陈
```

特点：

> 多是体制内权臣、军功集团、士族集团夺权，然后用“禅让”包装。

典型交接：

- 汉 → 魏：曹丕逼汉献帝禅让
- 魏 → 晋：司马炎逼魏禅让
- 晋 → 宋：刘裕篡东晋
- 宋 → 齐 → 梁 → 陈：南朝内部权臣更替
- 陈 → 隋：隋灭陈，不是禅让

### 南北两条线最后汇合

```text
南线：汉 → 魏 → 晋 → 东晋 → 宋齐梁陈
                                  \
                                   → 隋 → 唐
                                  /
北线：北魏 → 西魏 → 北周
```

隋灭陈后，南北重新统一。

## 宋以后性质变了

宋以后仍有正统顺序：

```text
宋 → 元 → 明 → 清
```

但不再像前面那样是清晰的“统治集团内部长线”。

交接性质：

- 宋 → 元：蒙古征服
- 元 → 明：农民起义、军事推翻
- 明 → 清：明末内乱 + 满洲入关
- 清 → 民国：革命终结帝制

所以：

> 宋以前很多是“体制内夺权”；  
> 宋以后更多是“征服、起义、革命式断裂”。

中国古代“正统线”常是连续的；但实际政权更替并不总是和平继承。  
宋以前常见统治集团内部换姓，宋以后则更多表现为外部征服、社会起义和制度性断裂。
