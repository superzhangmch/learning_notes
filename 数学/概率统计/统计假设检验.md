不只是平均值可以做假设检验, 其他比如中值, 也可以做. 可以是断定你拍定的 μ₀ 和 ground truth mean 是否相等, 其实也可以做是否大于(而非等于)的假设检验.

下面只看关于平均值的. 那么就是: ground truth 的均值你不知道, 只好有个自己的猜测, 拍定一个均值 μ₀, 然后是通过实际采样看是否背后的 ground truth 是否就是 μ₀.

这涉及到下面的分布:
- 原数据真实分布: 这个我们是不知道的. 我们不知道它的真正均值 μ.
- 采样分布: 被关注的统计量(比如均值)的采样分布. 假设一次采样时sample 100个, 那么这100个样本的均值服从什么概率分布? 这个分布就是采样分布. 它由两个东西决定: 一次采样的数量n, 以及你拍定的那个猜测 μ₀. 不同的 n与 μ₀ 对应不同的采样分布.
  * 原始数据分布你都不知道, 凭啥你能根据 n 和 μ₀ 断定精确的采样分布? 实际中, 都是取近似: 先假设采样分布服从某个分布, 而这个假设的采样分布本身有一定要求, 只要要求能满足, 则要么采样分布就是精确的, 要么是很好的近似. 比如对均值假设检验: 如果原始数据时正态分布, 则t分布就是精确的采样分布; 如果原始数据不是正态分布, 只要它还满足中心极限定理(比如柯西分布就不满足), 那么只要n比较大, 单次抽样的均值就比较接近真值(所以中心极限定理这里作用于单次抽样, 而不是多次), 这时用t分布也是很好的近似.

有了采样分布（注意它的构造和当前的采样结果无关, 当前采样只是该分布的一个具体sample而已), 就可以算 p-value了: 当前这次n抽样，只是采样分布中一个点，于是可以算出分布密度图中比这个点（即本抽样的均值）更极端的整个区域的面积或概率，这就是 p-value。如果当前抽样处于采样分区图密度稀疏区，基于小概率实践不容易发生原则，判定要么是你的mu_0猜测不对，要么是猜测对但是小概率事件发生了。检验假设用的是前者：你猜错了, 这正是一种反证法的思想。

注意：
- 需要先猜测后抽样做假设检验，如果拿采样到的n个的均值用来做，一定是相等的。没意义。
- n 太大也不好。n 越大越置信，但是现实中不可能100% 猜对μ₀，这样如果n太大会导致再精准的定位猜测都是有显著差异了——永远告诉你二者差异显著, 你拿不到真正关心的结论了。
- n个样本点要独立.
- 从上面内容可见
  * pVal 不是groud-truth 分布的概率, 也不是猜测的分布上的概率, 而是采样行为的分布上的概率; 1-p_val 不代表"有显著差异"的概率.
  * 你的猜测 H₀ 为真时 p 值服从 0 到 1 均匀分布: p 就是"我这次排第几个百分位"，百分位天生均匀。以及它被破坏的三种方式：参照分布用错、统计量离散、H₀ 本来就假。
 
### 置信区间:

什么是置信区间呢：所有的使得当前采样按同一 p-val 阈值都不显著(也就是有差异)的所有 μ₀ 构成的集合，就是置信区间。也就是说，置信区间是关于好多个采样分布而言的，而非基于当前采样分布。它单纯是基于当前具体的n采样算出的, 独立于你猜测的 μ₀——可以先推算置信区间, 然后看你的 μ₀ 是否被他覆盖.

单词抽样的95%置信区间, 即代表ground-truth 有95%概率在其中, 也代表抽样n次, 有95%的抽样真的覆盖住了ground-truth.

现实中, 除了看p-val 还要关注置信区间.

### 显著性α/置信区间/p-val 关系: 

显著性α/置信区间是同一个东西的两面. α 和 p 都是同一条采样分布的密度图上"某个切点以外的尾巴面积"，区别只在切点是谁定的。

```
横轴 = 统计量 t,  曲线 = H₀ 为真时它的密度

                      ___
                    /     \
                  /         \
              __ /             \ __
          ────┬──────────┬───┬──────→  t
           −t_crit     t_obs  t_crit

  α    = t_crit 以外两侧尾巴的面积     ← 切点由 你 事先定
  p    = t_obs  以外两侧尾巴的面积     ← 切点由 数据 定
  1−α  = ±t_crit 之间的面积(接受域)

  判定 p < α   ⟺   t_obs 比 t_crit 更靠外
```

所以"显著"这件事，用面积说是 p < α，用位置说是观测值比临界值更靠外，完全是一回事。顺带一个推论：p 的切点是随机的（观测值每次都变），α 的切点是固定的，这就是为什么 p 是随机变量而 α 是常数。

图中这条密度的横轴是统计量；置信区间是一段参数 μ 的范围。两者是不同的轴。
- 显著性水平 α: 在密度上, 是尾巴的面积
- 置信水平 1−α: 在密度上, 是中间的面积
- 置信区间: 不在密度上, 是把中间那段反演到参数轴之外的 μ 的产物

最后，这个视角还顺手解释了"为什么 H₀ 为真时 p 值均匀"：因为 p 的切分点（观测值）本身就严格服从那条密度，而把一个连续随机变量代入它自己的分布函数，结果必然是 0 到 1 上的均匀分布。

### 功效 -  power/statistical power

|            | 真相：H₀ 为真 | 真相：H₀ 为假 |
|------------|---------------|---------------|
| 判定拒绝   | α = 5% / 第一类错误 | 功效 / 正确 |
| 判定不拒绝 | 1 − α = 95% / 正确 | 1 − 功效 / 第二类错误 β |
| 列和       | 1             | 1             |

- 第一类错误: H₀ 为真, 你却拒绝了它, 错杀
- 第二类错误: H₀ 为假, 你却没拒绝它, 放过
- α: 被硬性控制在 5%(或 1%), 是一条纪律
- β: 只是"希望不超过 20%"(即功效 ≥ 80%), 是一个目标

## 用于实际

常用的几个场景：
- 一次采样n个，看均值是否和猜测一样。
- 对采样的 n 个点，两次对他们做测量，看前后是否有差异。（配对）
- 做两次测量，每次采样不同数量的样本点, 采样两次, 看两次是否有显著差异。（不配对）
- 时间序列配对: 按时间配对的两个时间序列集合，是否二者差异显著

对以上:
- 配对对比: 直接每个点上求差, 看这个差集就行, 仿佛一开始采样了n个diff: 把 {x_i − y_i} 当成一列新采样到的数，检验它的均值是否为 0。
- 不配对对比: 如果配对会更好——为达到同样的显著验证, 不排队搞需要更多的样本点(比如看一种糖尿病药物有效性: 看同一批人用药前后血糖值看药物效果只需要少量人; 如果不同的人, 那就是大量的人的用药前平均和用药后平均, 才容易看出效果差异. 直观上就能感觉出)
- 时间序列的对比: 统计检验一般是要求抽样的 n 个数据之间两两独立, 而时间序列的时间依赖性往往打破了这一点. 所以其实是要先验证t依赖是否可忽略(比如看差值序列的 ACF，或跑 Ljung–Box等), 不可忽略时, 当配对检验, 就会有问题.
  * 关于互联网功能验证那种 ab-test: 往往呈现出的是时间序列配对形式, 每天有了一些数据, 所以每天可以对feature 有一个对比的指标, 跑了2周, 看看哪个好. 看起来就是这个时间序列配对看效果的场景. 实际中, 标准做法并不是这样处理的. 见下文.

另外, 对于配对类的, 如果不同样本本身均值都不太有意义或很不可信(但是因不同地区, 不同类别等, 其实还好; 配比的方法就把这种差异消除了), 或你其实关心的是谁好而不是差多少(关心P(X>Y)), 那么就应该用符号有关的检验等(Wilcoxon 符号秩 或 符号检验), 而不是t-test之类.

| 场景                     | 被检验的量 | H₀      | 主检验               | 稳健替代                     | 关键要点                                      |
|--------------------------|------------|---------|----------------------|------------------------------|-----------------------------------------------|
| ① 一组 n 个点 vs 猜测值  | μ          | μ = μ₀  | 单样本 t             | 符号检验                     | "单样本"数的是组数，一组里有 n 个观测         |
| ② 同一批点测两次（配对） | μ_d        | μ_d = 0 | 配对 t               | Wilcoxon 符号秩              | 先减后平均，退化成①，μ₀=0；s_d 是差值的标准差 |
| ③ 两组独立，n 可不等     | μ₁ − μ₂    | = 0     | Welch t              | Mann–Whitney U               | n 不等不需特殊处理；别用等方差合并版          |
| ④ 配对但只关心"谁更好"   | P(X>Y)     | = 0.5   | 符号检验             | Wilcoxon 符号秩              | 换的是参数不是算法；对离群免疫                |
| ⑤ 按时间配对的两条序列   | μ_d        | = 0     | 先查自相关，再配对 t | HAC / block bootstrap / 置换 | 破坏的是"对与对独立"；n_eff ≈ n(1−ρ)/(1+ρ)    |

## 关于 ab-test

这里看互联网的点击率 CTR 提升策略这一类场景的 ab-test. 一般是把用户群体分组, 实验n天, 每个用户的分组始终不变. 通过统计曝光和点击, 看哪一个分组的 ctr 更高.

人的直觉是, 急于看到效果数据, 所以每天都会看当天的对比, 以及所有天的全量上的对比. 然后盯着每天的对比走势图, 希望新策略curve 总在旧策略curve之上.

怎么衡量新旧对比呢? 

假设是实验 10 天, 并不适合弄成 10 个样本的配对数据来搞. 这会导致: 无论你有多大的用户量, 你都搞成了 n=10 的检验, 把数据都浪费了, 本来显著的, 反而不显著了. 

正确的方式是: 把所有数据聚合后看(仿佛1天有10天的量; 从而对于单个天, 也可以这么搞), 从a、b两个分支的曝光与点击量来弄, 这时候是按用户数当作n来做的检验, 所以充分利用了数据——统计"功效"更高，结果更稳定. 

注意聚合后, 不是n=1, 而是n=用户量. 按 ai, 所用的检验是 z-test, test 所用的数字是2个: a和b分别的曝光量和点击量. (到底怎么做的?)

这样的话, 对于大厂比如google等来说, 可能几秒或1分钟的数据, 就足以提供一个很大的样本数n, 并提供一个策略是否有显著差异的可靠检验. 那么google为什么并不会只是实验几分钟就断定策略效果呢? 这是因为: 检验假设只是说这1分钟的数据a/b两方是否有显著差异, 但是不关心这1分钟的数据的分布是否是真的代表原始数据分布的——而这正是问题, 至少要1天或一周, 才能保证采样的数据在时间上是覆盖了各种情况的, 更长时间, 能保证sample的数据点的分布和真实分布更一致. 一句话, 更长时间, 除了积累样本书(如果流量小), 更重要的, 还包括样本的场景覆盖. 另外还可能有新奇效应, 开始虚高稳态后效果变低.
