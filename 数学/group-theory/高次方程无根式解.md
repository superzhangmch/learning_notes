### 阿贝尔 vs 伽罗瓦
阿贝尔证明了5次方程无根式解，伽罗瓦证明了五次及以上的一般情况。

### 5次及以上无根式解: 证明思路
基本思路是：从一个包含系数的基础域出发，逐步扩域（每次从上一个域中选一个元素的某次(次数可任意, 但是多取素数)方根作为扩域元素）。如果方程有根式解，那么这样一直扩下去（构成扩域链，即根式塔），一定存在某个域能包含所有根——也就是说，某个扩域包含了方程的分裂域 L（包含所有根的最小域）：

K = F₀ →F₁ →F₂ →F₃ → ⋯ →Fₙ ⊇L.

然后用反证法：假设方程有根式解，由此推出矛盾；从而说明这样的"根式塔"根本无法构建，于是不存在通用根式解。

其证明的妙处，就在于如何用群论来完成反证：假设有根式解，且直通分裂域的根式塔已经建立。那么可以在分裂域 L 上定义 Galois 群 Gal(L/F)，其群元素是 L 上的一类特殊自同构：在子域 F 上保持不变，而对所有根实施某种置换。L/F 只是记号, 不代表求商, 只表示在F上有约束.

若有 n 个根，则置换共有 n! 个，但并非所有置换都能构成域同构（须保持加法与乘法结构），所以 Gal(L/F) 只是 n 阶对称群（置换群）的某个子群。由于这些自同构都固定子域 F 中的元素不变， F 越大，约束越强，群越小。 Fᵢ 是域的从小到大的包含链，而 Gal(L/Fᵢ) 则构成反向的包含链。

数学上可以证明，伴随 F₀ →F₁ → ⋯ →Fₙ 所构造的 Gal(L/Fᵢ) 满足： Gal(L/Fᵢ₊₁) 是 Gal(L/Fᵢ) 的正规子群，且商群是循环群。满足这一条件的 $Gal(L/F₀)$ 称为可解群(可解群实际定义中放宽为交换群即可)。

反证的关键在于：若发现 Gal(L/F₀) 的正规子群列分解后，商群并非都是循环群，则说明根式解根本不存在。注意 Gal(L/F₀) 是客观存在的，不依赖于根式塔是否存在；而 Gal(L/Fᵢ)（i ≠0）则需要根式塔存在才能谈起（当然只要域 F 给定， Gal(L/F) 总是客观存在的）。

一般性的五次及以上方程，其 Galois 群同构于对称群 Sₙ，而 Sₙ（ n ≥5）是单群，不满足可解群的条件。(一般5次方程的Galois群是S5, 5个元素的所有置换构成的群，S5​的唯一非平凡正规子群是A5, 5阶交错群).

### 某些特殊的具体的 5次及以上方程有根式解

反之, 若某方程的 Gal(L/K) 是可解群(即正规子列商群是交换群), 则它有根式解. 每个具体方程的Galois群并不一样(虽然复杂, 其实是可以具体算出的), 是有可能是可解群的.

可解群则有根式解，原因在于：根据 Kummer 理论，可以依照正规子群分解列，构建出对应的 K = F₀ →F₁ → ⋯ →Fₙ → ..，使得分裂域 L 包含于某个 Fₙ。怎么构建: 先将 Gal(L/F₀) 的正规列作循环化细分（将交换商群进一步分解为循环群(这是一定可以分解的)，同时加细正规列），然后逐步添入各阶单位根进行扩域，再按 Lagrange 预解式的方式逐步扩域，直至包含 L。

## 有根式解 => Gal群可解, 详细证明

**(1). 假设有根，从而有根式塔：**

设根式塔存在 K = F₀ ⊂ F₁ ⊂ F₂ ⊂ ··· ⊂ Fₘ ⊃ L，其中每一步 Fᵢ₊₁ = Fᵢ(βᵢ)，βᵢⁿⁱ = bᵢ ∈ Fᵢ。注意 bᵢ 来自上一个 Fᵢ，nᵢ 可任取。

```
域 (Field Tower)                    对应关系
═══════════════════════════════════════════════════════

        Fₘ  ⊇  L
        │
        │  βₘ₋₁ⁿᵐ⁻¹ = bₘ₋₁ ∈ Fₘ₋₁
        │
       Fₘ₋₁
        │
        │  β₂ⁿ² = b₂ ∈ F₂
        │
        F₂
        │
        │  β₁ⁿ¹ = b₁ ∈ F₁
        │
        F₁  =  F₀(β₀)
        │
        │  β₀ⁿ⁰ = b₀ ∈ F₀
        │
        F₀  =  K  (基域)

每步: Fᵢ₊₁ = Fᵢ(βᵢ),  βᵢⁿⁱ = bᵢ ∈ Fᵢ
```

**(2). 子群关系成立：**

看单独一步：Fᵢ ⊂ Fᵢ₊₁。考虑 Gal(L/Fᵢ) 和 Gal(L/Fᵢ₊₁)。由 Galois 对应：Gal(L/Fᵢ₊₁) ⊂ Gal(L/Fᵢ)，这是因为自同构定义在 L 上，而子域 Fᵢ₊₁ 比 Fᵢ 大，固定 Fᵢ₊₁ 的约束更强。

**(3). 正规子群关系成立：**

关键问题：Gal(L/Fᵢ₊₁) 是 Gal(L/Fᵢ) 的正规子群吗？商群是交换群吗？

为了证明是正规子群, 根据群的知识, 只需证明它是某个群同态的 kernel. 这个同态是L上自同构 σ1 -> 某自同构 σ2 的某种映射. 

**σ ∈ Gal(L/Fᵢ) 是 xⁿⁱ - bᵢ = 0 的根的一个置换**

取任意 σ ∈ Gal(L/Fᵢ)，它作用在 βᵢ 上： σ(βᵢ)ⁿⁱ = σ(βᵢⁿⁱ) = σ(bᵢ) = bᵢ, (注意 βᵢⁿⁱ = bᵢ ∈ Fᵢ, 而 βᵢ 是扩域的种子), 所以 σ(βᵢ) 也是 xⁿⁱ - bᵢ = 0 的根. 也就是说 σ(βᵢ) 和 βᵢ 都是该方程的根. 根据xⁿⁱ - bᵢ = 0 方程的知识, $σ(βᵢ) = ζ^{j(σ)} · βᵢ$，其中 j(σ) ∈ {0, 1, ..., nᵢ-1} 是 σ 把 βᵢ 映到第几号根(不是原方程, 而是说xⁿⁱ - bᵢ的第x号根)的下标, ζ = e^(2πi/nᵢ). 类似可证, 对 xⁿⁱ - bᵢ = 0 中的任意一根 r, σ(r) 仍是该方程的根, 而 σ 是双射, 所以 σ 把它的 root set { ζ⁰·βᵢ, ζ¹·βᵢ, ..., ζ^(nᵢ-1)·βᵢ } 映射到自身，是这个集合到自身的双射。

知识点: 设 β 是 xⁿ - b = 0 的一个特定根（就取定一个），那么所有根是：β, ζβ, ζ²β, ζ³β, ..., ζ^(n-1)β, 其中 ζ = e^(2πi/n) 是 n 次本原单位根。 

**定义同态：**

下面定义映射:  φ : Gal(L/Fᵢ) --> Z/(nᵢZ)，σ |--> j(σ)

验证这是群同态：设 σ, τ ∈ Gal(L/Fᵢ), (注意: 可假设(或先扩单位根) $ζ^{j(τ)} ∈ Fᵢ$ , 故 $σ(ζ^{j(τ)}) = ζ^{j(τ)}$, 而 $σ(βᵢ) = ζ^{j(σ)} · βᵢ$), 有:

$(στ)(βᵢ) = σ(τ(βᵢ)) = σ(ζ^{j(τ)} · βᵢ) = ζ^{j(τ)} · σ(βᵢ) = ζ^{(j(τ)+j(σ))} · βᵢ$  

所以：φ(στ) = j(σ) + j(τ) = φ(σ) + φ(τ) , 同态成立.

上面只看了 βᵢ 上的表现. 这样足够, 是因为: Fᵢ₊₁ = Fᵢ(βᵢ)，Fᵢ₊₁ 里的每个元素都是 βᵢ 的多项式（系数在 Fᵢ 里）： a₀ + a₁βᵢ + a₂βᵢ² + ... ,  aⱼ ∈ Fᵢ, 而 σ 已经固定 Fᵢ 不动，所以只要知道 σ 把 βᵢ 映到哪里，σ 在整个 Fᵢ₊₁ 上的行为就完全确定了。

注意, φ : Gal(L/Fᵢ) --> Z/(nᵢZ)，σ |--> j(σ), 本质就是在 xⁿⁱ - 1 = 0 单元圆的均分点集上的一个位置置换, 所以才映射到循环群. 这个置换, 只需要时域同构就行, 与原始高次方程没啥关系. 

**同态 =>正规子群**

- 按该同态定义: ker φ = { σ ∈ Gal(L/Fᵢ) | σ(βᵢ) = βᵢ }, 即保持 xⁿⁱ - bᵢ = 0 的根集合不变的那些.
- 按 Gal(L/Fᵢ₊₁) 定义: ker φ = Gal(L/F_{i+1}). 这是因为, σ 固定 βᵢ 不动，又固定 Fᵢ 不动，所以固定 Fᵢ(βᵢ) = Fᵢ₊₁ 不动, 这样的 σ 正好是 Gal(L/Fᵢ₊₁) 的元素.

也就是说, 核 = 下一层Galois群.

于是由群同态基本定理：Gal(L/Fᵢ) / ker(φ) = Gal(L/Fᵢ) / Gal(L/Fᵢ₊₁) ≅ φ(Gal(L/Fᵢ)) = Z/nᵢZ. 
- Gal(L/Fᵢ₊₁) ◁ Gal(L/Fᵢ) （核是正规子群）
- 商群是 Z/nᵢZ，是循环(当然更是交换)群 

**对每一步都做同样的事：**

Gal(L/F₀) ⊃ Gal(L/F₁) ⊃ ··· ⊃ Gal(L/Fₘ)

每一步都符合：是正规子群，商群交换。

最后一个 Gal(L/Fₘ) = ?  因为 Fₘ ⊃ L，固定 Fₘ 不动的自同构，也固定 L 不动，所以： Gal(L/Fₘ) = {e}

所以得到：Gal(L/K) = Gal(L/F₀) ⊃ Gal(L/F₁) ⊃ ··· ⊃ {e}. 每步正规，每步商群交换。这正是可解群的定义！于是得证 Gal(L/K) 是可解群

```
    域塔 (小 → 大)              Galois群塔 (大 → 小)
  ════════════════           ══════════════════════════

   L ⊂ Fₘ   #域最大           {e} = Gal(L/Fₘ)            # 群最小
```

另一个方向是 Gal群可解 => 有根式解. 上面的有根式解=>Gal group可解证明中可见, 所导出的商群一定是循环群. 而可解群的定义只要求交换群.

> 设 G 是有限交换群, 则存在正规子群列 G = G₀ ⊇ G₁ ⊇ G₂ ⊇ ... ⊇ Gₛ = {e}, 使得每个商群 Gᵢ/Gᵢ₊₁ 都是循环群.
>
> 证明: 有限交换群是循环群的直积, 自然有此分解.

**引理B: 循环扩张来自开根号 (即 Kummer理论)**

从上面两点容易看出, 如果原始 F0=K 若不包含单位根, 则先扩它成K'(数学上可证, 在此新的域上, 以及新的分裂域 L' 上(即同时含有原方程根, 以及单位根的最小域),  Gal(L'/K') 群仍可解, 于是会转为考虑L' 与 K'); 若正规列有商群是交换群, 则拆开它. 则变成了: K还有所需各种单位根, 且正规列商群都是循环群的情况. 然后对每个循环商群用引理B 开根处理即可.

### (1). 正规子群, 商群,正规子列

群的正规子群 N, 本质上等价于某个群同态f的一个 kernel. 且商群 G/ker 同构于 f(G). 因此N自动带有把群分成等价类的作用(通过 aN 配集的方式). N 满足 gNg⁻¹ 都属于 N.

根据 Jordan-holder 定理: 有限群(以及部分无限群)可以找到它的正规子群(且商群是单群), 而正规子群又能找他它自己的商群单的正规子群, 这样一直找下去, 大圈套小圈, 直到只剩下单位元素e. 这样的子群系列, 叫做合成列. 不同的合成列虽然看起来可能不一样，但分解出来的“简单成分”本质上是一样的，只是顺序可能不同。

子群大小是原群大小的因子(子群通过陪集概念, 把原始群划分成独立的集合, G = g₁H  ∪  g₂H  ∪  ...  ∪  gₖH; 陪集往往不是群). 从这也可以感觉出这个正规列的各群的大小.

### (2). Gal群的自同构: 为啥不是所有根置换都是自同构? 

不同的根可能有不同的**最小多项式**，根只能映射到**同一个最小多项式**的根。例子： $x^4 - 1 = 0$， $K = \mathbb{Q}$, 根： $1, -1, i, -i$，看起来有 $4! = 24$ 个置换。

但是 $$\sigma(1)^4 = 1 \quad \text{（这没有约束，四个根都满足）}$$, 用最小多项式约束：

| 根 | 最小多项式 | 只能映射到 |
|----|-----------|-----------|
| $1$ | $x-1$ | 只有 $1$ |
| $-1$ | $x+1$ | 只有 $-1$ |
| $i$ | $x^2+1$ | $i$ 或 $-i$ |
| $-i$ | $x^2+1$ | $i$ 或 $-i$ |

所以合法置换只有 $2$ 个，而不是 $24$ 个。

本质原因:  $$\sigma \text{ 是域同构} \implies \sigma \text{ 保持最小多项式}$$, 而不同的根，最小多项式可以不同，这就是筛子。一句话：根不能随便换，只能换到"代数地位完全相同"的根，而最小多项式不同的根，代数地位就不同。
