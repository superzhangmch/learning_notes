# Bootstrap

一句话: 把手里的 n 个样本当成总体，有放回地反复抽它，每次抽 n 个（和原样本一样多），模拟"整个实验重做一万遍"，得到一万个你关心的统计量，据此反推抽 n 个这种规模的实验算出的统计量有多不稳。

demo: https://superzhangmch.github.io/tiny_tools/demo/probability/bootstrap.html

### 问题是什么

想知道全国平均身高。量了 100 个人，算出θ̂=171.2 cm。真值θ，永远不知道. θ̂ 肯定不等于 θ。问题：差多少？本质上是说, 采样分布什么样子? 

不只是均值, 其他的比如中位数、任意分位数, 都可以用它. 实际上, 后面那些才真正令 bootstrap 发挥用武之地
- 对均值, 采样分布就是n+μ₀ 决定的t分布(但要求: 原数据正态或原数据不正态但 n 大)
- 换成中位数/基尼系数呢？没有对应的分布，谁也没推出来过。这时候, 就需要 bootstrap 了

### 两个"方差"
- 100 个人彼此的标准差    σ  ≈ 7 cm      ← 人和人差多少
- "平均身高"这个数的抖动   SE ≈ 0.7 cm    ← 你这个答案有多不稳
  * 差 10 倍（=√100）。**你交出去的是平均值，所以误差棒要 0.7，不是 7。**
  * SE 本来怎么得到: 如果能重做 20 次（每次换 100 个新人）, 这20个数的标准差就是 SE。但你只做了一次。

bootstrap 为了处理第二者.

### Bootstrap 怎么做

不找新人，从**手里这 100 个人**里**有放回**抽 100 个，算**平均**(对其他的统计量, 按各自的算出一个数字就行)。重复一万次。

```
原样本（缩到 8 人）  [168, 171, 175, 169, 182, 173, 160, 178]  → θ̂ = 172.0

重抽 [173, 168, 169, 168, 160, 169, 169, 171] → 168.4
     （168 抽中 2 次，169 抽中 3 次，175/182/178 一次没抽中）
重抽 [175, 182, 171, 168, 173, 169, 160, 178] → 172.0
重抽 [175, 173, 175, 173, 182, 160, 182, 168] → 173.5
```

**「有放回」是关键**——有人重复、有人漏掉，才会每次算出不同的数。

这一万个数的抖动 **≈ 真 SE**（实测比值 1.01）。

note:
那一万个数**不是一万个观测，是一万个"平均值"**，每个背后是一整份 100 人的重抽。不是「仿佛抽到了一万个人」，而是「仿佛把整个实验重做了一万遍」。

上面例子是均值. 给没有公式的统计量做区间**：中位数、任意分位数、基尼系数、P90÷P10、两组中位数之差、你自己编的任何指标——**这些都没有公式**, 都可以用它, 且对每一个**只改一行**：

```
算平均      m = sum(re) / n
算30%分位   m = sort(re)[0.3*n]
算基尼      m = gini(re)
```

### 怎么用: 本质在于用它可以得到所需统计量的抽样分布(的近似)

它把"求抽样分布"从要做数学推导，变成了跑个循环——这一万足够多的数, 基本上把采样分布刻画了出来. 想要什么就取什么：

```
标准差                  → SE（误差棒）
排序后第 2.5% / 97.5% 个      → 95% 置信区间
落在 H₀ 那侧的比例 × 2    → p 值（假设检验）
平均 − θ̂                → 偏差估计
SE ∝ 1/√n 反推           → 还需要采多少数据（实验设计）
对两组的差做一遍          → 组间比较是否显著
平均                    → ≈ θ̂，没新信息，扔掉
```

一个限制: 只给宽度，不给更准的点:
- 一万个 θ* 的平均 **精确等于** θ̂。它不引入新数据，不可能比 θ̂ 更接近 θ。想更准只能**多采数据**。
