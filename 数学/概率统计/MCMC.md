# MCMC = Markov Chain Monte Carlo，马尔可夫链蒙特卡洛

demo: https://superzhangmch.github.io/tiny_tools/demo/probability/mcmc_metropolis.html

我们想从某个复杂分布 p(x) 里抽样，但这个分布太复杂(往往也没具体表达式)，不能直接按这个分布抽。MCMC 正是这样一类用来从复杂概率分布中采样的方法。

它的方法是: 
- 设法构造一个马尔可夫链：x₁ → x₂ → x₃ → ⋯ 让这个链运行足够久以后，它接下来产生的所有样本近似服从目标分布 p(x)。
- 不要求每一步都独立从目标分布采样，而是构造一个马尔可夫链，让它的长期稳定分布等于目标分布。
  * 也就是说，虽然 xₜ₊₁ 依赖于 xₜ, 样本不是独立的，但当链运行足够久, 链收敛后，xₜ 的分布会接近 p(x)。因此，丢掉前期 burn-in 样本后，可以用后续样本用来做抽样.

### MCMC 基本原理

MCMC 做的事：构造一条随机游走的链，让它长期访问各个位置的频率等于目标分布。比如目标分布 p(x) 在 A 区域概率大，在 B 区域概率小，MCMC 跑久后就会：经常去 A, 偶尔去 B, 很少去极低概率区域, 最后这些点就可以当作来自 p(x) 的样本。

### 具体怎么操作？

最简单的 Metropolis 算法：假设当前在 x, 重复下面好多次:

- 1. 提议一个新点: x' = x + random noise, 比如：x' = x + ε, ε ∼ N(0, σ²)
- 2. 比较新旧点的概率, 算出接受概率: 算 r = p(x')/p(x) , 接受概率 α = min(1, r)
  - 即: 如果新点概率更高(r>1)，直接接受。如果新点概率更低(r<1)，也按比例接受。
- 3. 接受或拒绝: 抽一个随机数 u ∼ Uniform(0,1), 如果：u < α, 就移动到 x'。否则留在 x。

### 但现实中不知道密度函数，怎么做？

MCMC 不需要知道完整密度 p(x)，只需要知道一个和它成比例的东西。p(x) = f(x)/Z, 即使归一化因子 Z 不知道也没关系。因为 MCMC 只用比值：p(x')/p(x) = f(x')/f(x), 归一化常数 Z 抵消了。

所以只要能算：f(x) ∝ p(x) 就可以做。

### ML 里通常怎么有这个 f(x)？

(1). 贝叶斯模型

想采样参数后验 p(θ|D), 完整后验不知道，因为：p(θ|D) = p(D|θ)p(θ)/p(D). 但 MCMC 只需要：p(θ|D) ∝ p(D|θ)p(θ). 所以令：f(θ)=p(D|θ)p(θ) 就能做。

也就是说，ML 里你通常知道：likelihood 模型生成数据的概率/prior：参数先验, 不知道的是归一化常数 p(D)，但 MCMC 不需要它。

(2). 能量模型 EBM

模型定义：p_θ(x)=(exp(-E_θ(x)))/Z_θ, 虽然 Z_θ 不知道，但能量 E_θ(x) 是神经网络给的。所以 p_θ(x) ∝ exp(-E_θ(x)), MCMC 可以用：f(x)=exp(-E_θ(x))来采样。

(3). 如果连 f(x) 都不知道呢？那普通 MCMC 不能直接用。如果你既不知道 p(x) 也不知道 f(x)∝p(x), 那 MCMC 没法判断新点比旧点更可能还是更不可能。

这时候要用别的方法，比如：

- ABC
- likelihood-free inference
- simulation-based inference
- GAN
- diffusion / score-based model
- normalizing flow
