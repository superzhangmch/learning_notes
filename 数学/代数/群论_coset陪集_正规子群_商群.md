设 H ≤ G，对任意 g ∈ G：
- 左陪集： gH = {gh | h ∈ H}
- 右陪集： Hg = {hg | h ∈ H}

0. 陪集一般不是群. 但是至少 eH = H 是群.
1. 同一陪集内的元素可以互换代表元: g₁ ∈ g₂H ⇔ g₁H = g₂H. 陪集内**任意元素**都可以作为代表元，描述的是同一个集合。
2. 等价关系:  $g₁H = g₂H ⇔ g₂^{-1}g₁∈ H$
3. 陪集要么完全相同，要么完全不相交: g₁ H = g₂ H 或 g₁ H ∩ g₂ H = ∅
4. 所有陪集等大: |gH| = |H| 对所有 g ∈ G, 映射 h ↦ gh 是 H → gH 的双射。
5. 陪集构成 G 的一个划分: 所有左陪集不重不漏地覆盖 G： $G = ⨆_{g ∈ [G/H]} gH$, 其中一个正是 H 自己.
6. Lagrange 定理: (由性质 3、4、5 立刻得到) |G| = |H|⋅[G : H]. 其中 [G:H] 是陪集的个数，称为 H 在 G 中的**指数（index）**。
 - 推论：|H| | |G|
7. 正规子群与商群: 一般情况下，左陪集 ≠ 右陪集。但若 H ⊴ G（正规子群），即：gH = Hg 对所有 g ∈ G, 则陪集之间可以定义乘法：(g₁H)(g₂H) = (g₁g₂)H, 所有陪集构成一个群，称为**商群** G/H。
  - Coset 是连接 G 与 G/H 的桥梁：  
  - H 是被"忽略"的对称性，G/H 是"剩余"的对称性。

----

### 具象化理解

(1). 最好的例子：整数模 n. 取 G = ℤ，H = 3ℤ = {…, -6, -3, 0, 3, 6, …}

所有陪集：
```
0 + 3ℤ = {…, -6, -3, 0, 3, 6, …} 余数为 0 的整数
1 + 3ℤ = {…, -5, -2, 1, 4, 7, …} 余数为 1 的整数
2 + 3ℤ = {…, -4, -1, 2, 5, 8, …} 余数为 2 的整数
```
**Coset 就是按余数分类！** 同一个 coset 里的整数，除以 3 余数相同。

(2). 更几何的例子：二维平面上的平移

取 G = ℝ²（向量加法），H = x 轴 = {(x, 0) | x ∈ ℝ}. 陪集 (0, c) + H：{(x, 0) + (0, c) | x ∈ ℝ} = {(x, c) | x ∈ ℝ}, 这就是**高度为 c 的水平线**！

```
y
↑
─────────────────  (0,2) + H,  c=2
─────────────────  (0,1) + H,  c=1
────────── H ────  c=0  （H 本身，唯一是群的陪集）
─────────────────  (0,-1)+ H,  c=-1
─────────────────  (0,-2)+ H,  c=-2
                          → x
```

> 每一条水平线就是一个 coset！  
> H 是 x 轴，其他 coset 是与 x 轴**平行**的直线。  
> 所有水平线**铺满**整个平面，互不重叠。

(3). 总结

> Coset 就是**子群 H 在群 G 里的平行副本**。  
> H 是"原版"，其他 coset 是被某个元素"平移"后的副本，大小形状完全相同，共同**无缝拼满**整个群 G。

所以, 对于gH=Hg, H 才可以天然定义商群. 对于一般 H, 也是可以用 coset 定义商结构(商集), 只是不是群(只有gH=Hg, 可以有良好乘法定义, 成为群).
