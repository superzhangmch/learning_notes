一般变系数线性 ODE，不存在用初等函数表达闭合解的通用算法。这不是"还没找到"，而是已经被证明不存在（类比Abel证明五次方程无根式解）。

对于常系数ODE aₙy⁽ⁿ⁾ + aₙ₋₁y⁽ⁿ⁻¹⁾ + ⋯ + a₁y' + a₀y = 0, 通解的形式已知: 根据系数可以构建一个矩阵, 并根据特征值有通解为:
- n 个不同实根 λ₁, ⋯, λₙy = C₁ e^{λ₁ x} + ⋯ + Cₙ e^{λₙ x}
- 实根 λ 有 k 重y = (C₁ + C₂ x + ⋯ + Cₖ xᵏ⁻¹)e^{λ x}
- 共轭复根 λ = α ± β iy = e^{α x}(C₁ cosβ x + C₂ sinβ x)
