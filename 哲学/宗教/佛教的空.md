### 空

佛教说空, 这个空指的是无自性(乃佛家术语). 什么是自性, 就是事物本质, 也就是柏拉图的洞穴本质. 所以这个空, 就是说事物没真本质. 而原因在于变与依赖. 所以并不是说事物就是梦中的事物一样的空.

"本来无一物, 何处惹尘埃", 是说没有恒定的可以叫某物的东西, 而不是说变的东西也不存在.

本质不存在, 现象存在, 佛家说法是: 人活在世俗谛(现象)里，却以为那是胜义谛(本质).

**空本身也是空的:**

另外, 按禅宗/中观说法, 佛家会觉得一说空, 就牵扯到有, 还不是真正的空. 真正的"空"，不需要用"空"这个字来证明自己——一说"空"，已经不空了。假有（现象存在）× 真空（无固定自性）= 中道.
- 龙树: “空”本身也是空. 也就是, 本质不存在, “本质不存在“也是不存在的. 也就是说, 本质是否存在, 不再是一个值得探讨的问题. 

古希腊赫拉克利特（Heraclitus）："人不能两次踏入同一条河"/"万物皆流，无物常驻"（Panta Rhei）, 它否定了不变, 万物在流动，但是认为变化本身是永恒的规律（Logos）. 而佛教更进一步：连"变化"这个规律本身，也不是一个可以执着的实体.

note: 印度教是认为恒定的本原存在的. 与佛教相反.

### 龙树否定了啥, 仍然承认啥
 
- 龙树确实否认的（柏拉图式的）：有一个固定、自足、不依赖条件的本质（svabhāva / 自性），比如"马性"本身独立存在于马之外，永恒不变。这就是他在《中论》里批判的核心——自性（svabhāva）不存在。
- 龙树明确承认的：那个暂时稳定、缓慢变化、依条件存在的东西，可以叫"某某"。这正是他的二谛理论（二重真理）的核心.

| | 胜义谛（最终真理） | 世俗谛（约定真理）|
|---|---|---|
| 内容 | 一切法无自性、空 | 名言、概念、"马"、"我"等**可以使用** |
| 龙树态度 | 这里否认自性 | **这里完全承认** |

| | 柏拉图 | 龙树 |
|---|---|---|
| "马性"独立存在？ | ✅ 是 | ❌ 否 |
| 眼前这匹马可以叫"马"？ | ✅ 是（分有马性） | ✅ 是（约定命名，依缘存在） |
| 命名的根据是什么？ | 超越界的本质 | 条件聚合的稳定模式 + 语言约定 |

他在《中论》第24章明确说：「若不依俗谛，不得第一义」, 不承认世俗谛（约定命名），你连"空"都没法讲。

### 佛教世界观

它不是先构建地基而是倒着来: 

```
观察到"苦"
    ↓
苦从哪里来？→ 贪嗔痴（三毒）
    ↓
贪嗔痴造成什么？→ 业（Karma）← 因果在这里
    ↓
业积累之后？→ 推动轮回（Saṃsāra）← 轮回在这里
    ↓
轮回的本质？→ 空: 无常、无我、缘起
    ↓
看穿之后？→ 涅槃，出离轮回
```

### 关于因果与轮回

因果与轮回是为了体现苦的. 

万物无本原、无自性、空 vs 因果是真实的，轮回是真实的. 因果和轮回本身，不也需要一个"自性"来支撑吗？佛教内部的三种回答:
- 缘起就是因果: 因果不需要本原来支撑, 因果本身就是缘起, 就是事物之间的相依关系
- 因果是世俗谛:
  - 胜义谛：万物空，无自性
  - 世俗谛：因果、轮回真实运作
- 阿赖耶识（唯识宗）, 这是佛教内部觉得前两个回答不够用，专门发展出来的：阿赖耶识（藏识）, 储存所有业的种子, 跨越时间传递因果
  - 公元4-5世纪, 才出现的阿赖耶识解释, 乃一家之言

要同时维持两件事：无自性 vs 因果轮回, 佛家一直没有很好解法.

### 各派观点

四圣谛(, 这是佛陀最早说的，所有宗派都接受：
- 苦谛：生命中有苦
- 集谛：苦有原因（渴爱/执着）
- 灭谛：苦可以熄灭
- 道谛：有方法可以做到

所有宗派争论的，都是外围问题
- 苦的根源到底是什么？→ 各宗派解释不同
- 怎么修？→ 各宗派方法不同
- 涅槃是什么状态？→ 各宗派描述不同
- 因果轮回怎么运作？→ 各宗派解释不同

"空"不是佛陀最早说的，是后来发展出来的. 公元2-3世纪, 龙树把"空"系统化、哲学化.
