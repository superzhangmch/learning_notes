选择公理(Axiom of Choice, AC), 本身是集合论的内容. 其他地方用到它, 是因为集合论是数学基础, 无处不在而已. 作为公理化的集合论的内容, 有它没它决定了什么可以算作一个集合的集合的定义. 

## ZF 公理体系

(1). 公理有哪些

(下面axioms, 不知道全不全)
- **外延公理** 两个集合相等 ⇔ 元素完全相同
- **空集公理** 存在空集 ∅
  - 为什么需要： 集合论要有个起点。光有构造规则，没有初始对象，什么都造不出来。空集是一切集合的"原材料零件"。结合外延公理，空集是唯一的，记作 ∅。
- **配对公理** {a, b} 是集合
  - 它是从已有集合生成新集合的最基本手段之一
- **并集公理** 给一个集合的集合 ℱ，可以把 ℱ 里所有集合的元素合并成一个新集合 ⋃ℱ
- **幂集公理** 给任意集合 A，它的所有子集构成一个新集合 𝒫(A)
  - 为什么需要： 没有它，子集的"全体"只是一个说法，不是合法的集合，不能作为对象使用。
- **无穷公理** 存在无穷集合.如果没它, 你可以用其他公理 ∅ => {∅} => {{∅}} => {∅, {∅}} …… 一路造下去, 但是因为都是有限步, 造出的集合都是有限集合。不管怎么配对、并集、幂集，每次操作结果都是有限的。你永远造不出一个无穷集合。没有 ℕ，没有 ℝ，数学地基塌了。无穷公理就是专门声明：存在一个无穷集合。
  - 等于说他声明了极限集合的存在.
- **分离公理模式** 给一个已有集合 A 和一个性质 φ，可以从 A 里筛出满足 φ 的元素，构成子集: B = {x ∈ A | φ(x)}
  - 为什么需要 A：朴素集合论允许 {x|φ(x)}——任意性质直接定义集合。Russell 悖论证明这是灾难性的：令 φ(x) := x∉x，得到矛盾。分离公理的修复是：必须在一个已有集合内部筛选，不能凭空造集合。
- **替换公理模式** 如果 φ(x,y) 在集合 A 上定义了一个函数（每个 x ∈ A 对应唯一的 y），那么这个函数的像是一个集合: B = {y | ∃ x ∈ A, φ(x, y)}
  - 为什么需要： 分离公理只能造子集，像不能比原集合大。替换公理突破了这个限制，允许把集合"映射"到一个全新的集合上。很多序数、基数的构造离不开它。分离是"筛"，替换是"换"。
- **正则公理** 对任意非空集合 A，至少存在一个元素 x ∈ A，使得 x ∩ A = ∅。至少一个，可以有更多。
  - 在 ZFC 里，所有东西都是集合。元素也是集合，没有"纯粹的元素"这种东西。所以说 x ∈ A，x 是 A 的元素，同时 x 本身也是一个集合，可以有自己的元素，可以和别的集合求交集。
  - 它是来排除病态情况的: (1). 集合包含自身 A = {A}, A 是一个集合，但它的唯一元素是它自己。(2). 循环包含 A ∈ B ∈ A (3). 无穷下降链 ⋯ ∈ A₃ ∈ A₂ ∈ A₁ ∈ A₀, ∈ 关系一直往下，没有底。

数学研究的对象, 都是以某种编码的方式, 通过以上公理呈现的, 比如:
- 自然数 N:
  - von Neumann 编码: 0 := ∅; 1 := {∅} = {0}; 2 := {∅, {∅}} = {0, 1}; 3 := {∅, {∅}, {∅, {∅}}} = {0, 1, 2}
    - 正是由无穷公理, 保证了由此方法推演出的 N 存在
  - Zermelo 编码：0 := ∅, 1 := {∅}, 2 := {{∅}}, 3 := {{{∅}}}
- 有了N, 有理数Q、实数R, 都可以编码出

(2). 哪些不是集合

ZFC 构造出来的集合，构成一个宇宙，叫做 V = $⋃_{α} V_α$, ZFC 声明的集合，都在这个 V 里面。但 V 本身不是集合. (如果它是集合，就可以对它用分离公理，造出：R = {x ∈ V | x ∉ x}, 这就是 Russell 悖论，矛盾).

不在 V 里的: 真类（proper class）：

| 对象 | 原因 |
|------|------|
| 所有集合的全体 V | 太大，装不进集合 |
| 所有群的全体 | 太大 |
| 所有序数的全体 | Burali-Forti 悖论 |

这些东西"存在"，但不是集合，在 V 之外。

但所有"正常数学"用到的对象：ℕ, ℤ, ℚ, ℝ, ℂ, 函数、多项式、拓扑空间、流形、群、环、范畴……, 都在 V 里(适当编码后)。

## 加上 AC => ZFC 公理体系

(1). 什么是 AC

**选择公理（AC）** 对任意一族非空集合，**存在一个选择函数** f，使得 f 从每个集合里恰好取出一个元素。这个 f 的值域 {f(A) | A ∈ ℱ} 就是那个"选出来的集合"。

**ZFC = ZF + AC**，这是当代数学使用的标准集合论体系。
 
Gödel（1938）与 Cohen（1963）共同证明：

| 结论 | 含义 |
|------|------|
| **AC 与 ZF 相容** | ZF 无法证明 AC 为假 |
| **AC 独立于 ZF** | ZF 无法证明 AC 为真 |

> AC 是真正意义上的**公理**：加不加它，ZF 都是自洽的，但数学世界的样貌截然不同。

给定无限族非空集合 ${Aᵢ} _ {i ∈ I}$，AC 说：选择函数存在, $f: I → ⋃_{i ∈ I} Aᵢ, f(i) ∈ Aᵢ$. 这个 f 的值域：{f(i) | i ∈ I} 就是"选出来的集合"。

AC 的本质, 在于以一定方式, 扩充了什么样的集合存在: 无限族非空集合的"同时选取"是合法的. 它根本上是关于怎么从一个集合族, 获得另一额集合, 函数 f 只是描述"怎么取"的工具，不是重点。

没有 AC 之前，{f(i)|i∈I} 这个对象：你能描述它, 但不能保证它是合法的集合. ZF 的其他公理推不出它存在. AC 加进来之后：它变成合法的集合了. 这就是 AC 的意义.

集合的定义本身（外延公理）没有因为 AC 而变, 但"哪些对象是集合"这个范围扩大了.

(2). f 的存在好像是显然的啊, 为啥能有关于它是否存在的争论 (每个set 里任选一个, 这不很显然!)

首先要说, 如果是有限个集合, 每个集合都有限, 有限步遍历选取就行, 不会有任何问题. 问题出在无限个集合的时候.

A₁, A₂, A₃, … 无穷多个, 你说"每个里面取一个"，但：你用什么规则取？
- 如果每个 Aᵢ 都有具体结构，比如都是实数区间，可以说"取最小值"，这没问题，不需要AC。
- 如果 Aᵢ 是任意的非空集合，没有任何额外结构，没有大小，没有顺序，什么都没有：你没有任何规则可以描述"怎么取"。

例子: 
- 不需要AC: 平面上所有直线上分别取一个点构成的集合. (平面上所有直线, 是一个集合: 每条直线可以用斜率和截距来表示：(k, b) ∈ ℝ² , 再加上竖直线单独处理）), 直线上没有天然的第一个点, 或确定位置的点, 这个点集好像需要用 AC, 可是如果按: 都取和x轴的交点, 如果没有则取和y轴交点, 则不用 AC.
- 需要AC: ℝ 的所有(或可列个)非空子集，每个里面取一个元素，凑成一个集合。

注意: 无限族集合, 每个集合有限, 也可能是需要选择公理的. 如果没法统一的有限而具体的规则来指定.

(3). 争议
AC：只说存在，不说是哪个. ∃f, f(i) ∈ Aᵢ, 只说选择函数存在，但：不说 f 长什么样, 不说从每个 Aᵢ 里选的是哪个元素. 可能有很多个合法的 f，AC 不指定是哪一个. 这就是AC 被争议的根源. 构造主义数学家（比如 Brouwer）说：你说存在，但你造不出来，你给不出来，这算什么存在？

(4). 什么时候真正需要用 AC

集合数量: 有限/可列无限/不可列; 每个集合: 有限/可列无限/不可列. 组合后一共九种情况: 

| 族的大小 \ 每个集合 | 有限 | 可列无限 | 不可列无限 |
|-------------------|------|---------|-----------|
| **有限族** | ✗ | ✗ | ✗ |
| **可列无限族** | ✓ | ✓ | ✓ |
| **不可列无限族** | ✓ | ✓ | ✓ |

(note: 以上需要的组合, 特殊case 可能不需要) 

特别地, 对于可列无穷族集合, 有弱化版本的 AC: 可数选择公理 (Axiom of Countable Choice, CC), 对可列族非空集合，选择函数存在. 它比 AC 弱，只声明可列族的情况。可数选择公理, 直觉就是, 对于任一个集合, 你都能亲自给它做一个真实选择, 只是永远有不确定的一些sets, 没做选择.

不同强度的 AC:
- CC：可数选择公理 (Axiom of Countable Choice), 对可列族非空集合，选择函数存在
- DC：依赖选择公理 (Axiom of Dependent Choice), 如果每步选择依赖上一步的结果，这样的选择序列存在
- 强弱关系: CC  ⊂  DC  ⊂  AC

(5). 到底选择是否存在

ZF + ¬AC 与 ZF + AC 都是自洽的. 在ZF框架内, AC是否成立, 永远无法判断. 

## 依赖AC的重要定理

### (1). 与AC完全等价的（最强依赖）

这些定理和AC互相能推出对方，本质上就是AC的不同表述：

| 定理 | 领域 | 内容 |
|------|------|------|
| **良序定理** | 序理论 | 任意集合都可以被良序化 |
| **Zorn引理** | 序理论 | 有上界的偏序集有极大元 |
| **Tychonoff定理** | 拓扑 | 任意紧空间的乘积是紧的 |
| **向量空间有基** | 线性代数 | 任意向量空间都有Hamel基 |
| **极大理想存在** | 环论 | 任意非零环都有极大理想 |

### (2). 分析学

| 定理 | 内容 | 依赖强度 |
|------|------|---------|
| **实数的可列并** | 可列个可列集的并还是可列的 | CC够用 |
| **Hahn-Banach定理** | 线性泛函可以延拓 | 需要AC |
| **Baire纲定理** | 完备度量空间不是第一纲的 | DC够用 |
| **每个Hilbert空间有正交基** | 无限维Hilbert空间有基 | 需要AC |
| **Banach-Tarski悖论** | 球可以分解重组成两个等大的球 | 需要AC |

### (3). 代数学

| 定理 | 内容 | 依赖强度 |
|------|------|---------|
| **向量空间有基** | 任意向量空间有Hamel基 | 等价于AC |
| **极大理想存在** | 任意非零环有极大理想 | 等价于AC |
| **代数闭包存在** | 任意域有代数闭包 | 需要AC |
| **每个向量空间的基等势** | 基的势唯一确定 | 需要AC |
| **群有极大子群** | 无限群有极大正规子群 | 需要AC |

### (4). 拓扑学

| 定理 | 内容 | 依赖强度 |
|------|------|---------|
| **Tychonoff定理** | 紧空间乘积是紧的 | 等价于AC |
| **Stone-Čech紧化** | 任意完全正则空间有紧化 | 需要AC |
| **每个连通图有生成树** | 无限图有生成树 | 需要AC |

### (5). 集合论本身

| 结论 | 内容 | 依赖强度 |
|------|------|---------|
| **基数可比较** | 任意两个基数可以比大小 | 等价于AC |
| **可列个可列集的并可列** | | CC够用 |
| **ℵ运算正常** | 基数算术行为良好 | 需要AC |
| **每个无穷集包含可列子集** | | CC够用 |

### (6). 最反直觉的结论：Banach-Tarski 悖论

一个三维实心球，可以分解成有限块，重新拼装成**两个**和原来等大的球。
- 不违反物理  →  因为分解出来的"块"不是可测集, 根本不能赋予体积
- 违反直觉    →  因为我们默认分解出来的东西有体积
 
### (7). 依赖强度总结

- 等价于AC（最强）:良序定理，Zorn引理, Tychonoff，向量空间有基，极大理想
- 需要完整AC: Hahn-Banach，代数闭包，Banach-Tarski
- DC够用（中等）: Baire纲定理
- CC够用（最弱）: 可列集的并，每个无穷集有可列子集

AC影响的不是数学的边角，而是分析、代数、拓扑的核心定理。拿掉AC，现代数学大面积塌陷——这就是为什么数学家捏着鼻子也要接受它。
