超限归纳法依赖于一个良序. 然后对希望求证的性质P, 如果下面都成立, 则对全体序号成立:
- (1). 起点: 对序号 0, P(0) 成立;
- (2). 增1: 如果序号 a 成立, 则 P(a+1) 成立;
- (3). 极限步: 对极限序号: 如果任意 a < b 有 P(a) 成立, 则 P(b)成立

知识:
- 良序: 任意两个元素可比较先后(乃全序), 任何一个非最大元素有唯一的直接后序(不一定有前序), 任何一个子集合都有唯一最小序号. 
  * 对应到N 良序, 前两条很容易很整数上的表现建立直观关联. 实际上, "任何一个子集合都有唯一最小序号" 就能每个元都有直接后序(x>a 的所有x 集合, 有最小元, 它正是直接后序)
- 极限序号: 指的是类似 1, 2, 3, ..., infty(或者叫 ω), 这个infty. 

使用它的时候, 要点在于证明: 加一成立(就像一般归纳法), 极限情况也成立(任意有限n 都成立, 请证明在 ω 时也成立). 

因为需要一个良序, 所以好多时候, 需要用良序定理来构造出一个, 这时候涉及选择公理. 但不是使用到它的命题本质上都需要选择公理(见下面例子). 总之需要构造一个良序.

另外, 还有一个类似的, 超限递归做定义或做构造. 也是3步: 定义step1, 定义增1, 定义极限步.

选择公理 => 良序定理, 就用到了它: 为啥任意集合都能被良序(有最小元素开始的一种可以逐个往下数的一种序)

- 对集合S, 幂集 P(S), 存在. 根据AC, 有选择函数 f: P(S) -> S. 也就是可以每个子集选一个元素构成一个集合.
- 用超限递归(这是做定义, 做构造, 不是超限归纳做证明)造序列: 
  - 首元: 任意选 S 中一元 x₀, 乃良序之首元素. 选一个: x₁ = f(S \ {x₀})
  - 选下一个: 对已经选出的序列 {x₀, x₁, ..., xₙ}, 选 xₙ₊₁ = f(S \ {x₀, x₁, ..., xₙ}). 对于 ω+1 类似操作
  - 极限选择: 序号 ω=limit of {1, 2, ..., n, ∞}, x_ω = f(S \ {x₀, x₁, ..., xₙ, ..}). 其他极限步都类似操作
- 如是构造的序, 就是良序.

### 例子: ℝ 上的 Cantor-Bendixson 定理

导集: 对 ℝ 的一个闭集 F，定义导集操作：F' = {x ∈ F | x 是 F 的聚点, 即极限点}, 即去掉 F 中所有孤立点，剩下的集合。于是可以反复做导集操作: F⁽⁰⁾ = F -> F⁽¹⁾ = F' -> F⁽²⁾ = (F')' -> ... -> F⁽ⁿ⁺¹⁾ = (F⁽ⁿ⁾)'

可以定义极限: $F^{(λ)} = ⋂_{α < λ} F^{(α)} = F⁽⁰⁾ ∩ F⁽¹⁾ ∩ F⁽²⁾ ∩ ⋯$ (λ 为极限序数), 然后  $F^{(α+1)} = (F^{(α)})'$.

注意, 这时候 F⁽⁰⁾ ⊇ F⁽¹⁾ ⊇ F⁽²⁾ ⊇ ⋯ ⊇ $F^{(ω)} ⊇ F^{(ω+1)} ⊇ ⋯ ⊇ F^{(α)} = F^{(α+1)}$, 靠集合的包含关系, 就定义了一个良序.

**定理：对 ℝ 上任意闭集 F，存在一个可数序数 α，使得 $F^{(α+1)} = F^{(α)}$**
- 此时 $F^{(α)}$ 是一个完备集（每个点都是聚点），记为 P，而 F = P ∪ C, 其中：
  - P = $F^{(α)}$ ：完备集（要么是空集，要么与 ℝ 等势）
  - C = F \ P：可数集（被逐步去掉的孤立点）

证明:

(1). 超限归纳证明用来证明: $F^{(α)}$ 是闭集
- α = 0, F⁽⁰⁾ = F 是闭集
- 后继步骤：α = β + 1, F⁽ᵝ⁾ 是闭集，其导集 F⁽ᵝ⁺¹⁾ 也是闭集
- 极限步骤：α = λ, $F^{(λ)} = ⋂_{β < λ} F⁽ᵝ⁾$, 闭集的任意交仍是闭集

(2). 为什么一定会稳定？
- 每做一次导集，要么不变，要么严格缩小（去掉至少一个孤立点）。
- 每次去掉孤立点都对应一个不同的序数，而被去掉的点是孤立点, 是可数个（知识: ℝ上独立点集合是可数的），所以：最多去掉可数个点 ⇒ 在某个可数序数 α < ω₁ 处必然稳定
