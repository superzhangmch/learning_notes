
# 代数基本定理的证明

----

下面的, 主要用到 |p(z)| → ∞, 当 |z| → ∞

### 基于: 刘维尔定理/最大模原理

假设无零点, 则考虑 1/f(z), 它在 C 上解析, 且 |1/f(z)|→0 when z→∞. 由: 
- 刘维尔定理, 1/z==constant, 矛盾
- 由最大模定理, 最大模出现在边上, 随着C更大, 最大模却→0. 矛盾.

背后直觉: 没有零点的联通解析区域, 不会有凹陷. |f(z)|→∞当z→∞在, 这意味着大尺度上, |f(z)| 有凹陷, 与 |f(z)| 没零点则无凹陷矛盾.

### 有点像证明最大模原理的方法

|p(z)| → ∞（当 |z| → ∞），故存在大圆盘 C 使得 p 最小值在其内部取到。|p(z)| 是连续函数，在紧集 C 上**必取到最小值**，设最小值点为 z₀。

若 p(z₀) ≠ 0，在 z₀ 附近做局部展开, p(z₀ + ε) = p(z₀)(1 + cₖ εᵏ + O(εᵏ⁺¹)), k是展开后第一个不为零的项下标. 可证明, 可以选取适当的小 ε, 使得 cₖ εᵏ 为**负实数**(适当选取辐角即可)，则 |p(z₀ + ε)| < |p(z₀)| 与最小值矛盾。

如何取: 设 cₖ ≠ 0，写成极坐标形式：cₖ = |cₖ| eⁱᵠ, ε = r eⁱᶿ (r > 0), 则 cₖ εᵏ = |cₖ| rᵏ eⁱ⁽ᵠ ⁺ ᵏᶿ⁾. 要使它为**负实数**，只需： φ + kθ = π + 2mπ (m ∈ ℤ), 解得, θ = ((π - φ)/k) + (2mπ/k).

此方法, 约等于重新证明了最大模原理.

下面用到了, f(z)≈aₙzⁿ 当 z 充分大

### 基于: 辐角定理

f(z)≈aₙzⁿ 当 z 充分大. 于是 f(z) 在充分大的圆周上的随z走一圈的辐角应该是约等于 2nπ, 而同时 ∫_c f'/f dz = 0(f无零点, 则f'/f处处解析, 于是绕c积分是0) 而非 n* 2πi, 矛盾.

### 高斯的几何证明

对 f 按 z = x+iy 分解成 real(f) + img(f), 分别看 real = 0 和 img = 0 曲面的零曲线. 在充分大圆环上, 每条零曲线和这个圆有两个交点, 来自 real 和 img 的相邻曲线的交点交替出现(也就是 r1, i1, r2, i2, r3, i3, r4, i4, .. 这样. 其中 r-N, r-{N+1} 是 real 的曲线, i-N, i-{N+1} 是 img 的曲线), 于是这两条曲线必然有交点 - 即 f 的零点. 

"相邻曲线的交点交替出现": 当 z = Rⁱᶿ，R 充分大时， $f(z) ≈ aₙRⁿe^{inθ}$, 辐角 ≈ nθ + arg(aₙ)，随 θ 从 0 到 2π，辐角转过 2nπ，所以：
- re(f) = 0 的点：2n 个，均匀分布
- im(f) = 0 的点：2n 个，均匀分布
- 两组点**严格交替排列**（相位差 π/2n）
