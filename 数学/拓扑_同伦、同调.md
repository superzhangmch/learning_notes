下面是非常粗浅理解.

拓扑在于找到空间的洞. 同伦思想是, 一个圈(或者高维的球面)如果能连续缩成一个点, 说明这个圈内空间没洞(但是整个空间任意圈如此, 不代表整个空间没洞. 比如“球面”). 同调思想是, 如果我不是逐步缩这个圈, 而是设法用简单图形(比如 simplex 单形) 把内部填充, 那么也能证明这一点(为此, 要把所有 simplex 的border 带方向累加, 相na me挨着的边能抵消; 如果最后只剩下这个圈, 则说明完美填充了, 且内部无洞). 

同调比同伦更粗糙. 同伦能区分更多信息；同调通常只保留“线性化/阿贝尔化”的洞信息。

- 同伦：一个 (S^n) 映到空间里后，能不能在空间中连续缩成一点，等价于能不能延拓成一个 (D^{n+1})。
- 同调：一个闭合的 (k)-维 cycle 能不能作为某个 ((k+1))-chain 的边界。如果能，就说明它没有探测到同调意义下的洞；如果不能，就代表一个 (k)-维同调洞。

对于离散数据点, 可以把所有点扩大为小球, 从而数据连贯, 然后用同调方法来得到数据的拓扑结果. (TDA 分析)

### 同调的填充是否有洞, 可以用解线性代数方程方式算

通过这样的方法, 就是比较机械地判断了. 

第 0 步:发方向(纯约定,怎么定都行,定了别改)

- 每条边的官方方向:从小编号顶点指向大编号。记 [1,3] 就是 1→3;
- 每个三角形的官方走法:顶点按编号升序绕行。T = [1,2,3] 就是 1→2→3→1。

第 1 步:填矩阵的一列(一列 = 一个三角形的"用边报告")

沿三角形官方走法绕一圈,每走过一条边,查它的官方方向:

- 走向顺着官方方向 → 该边所在行记 +1;
- 走向逆着官方方向 → 记 −1;
- 三角形根本不挨这条边 → 记 0。

第 2 步:填右端向量(= 圈的"用边报告",规则一模一样)

沿圈走一遍,每条边同样按"顺官方 +1 / 逆官方 −1 / 没走过 0"记账。

也就是说:矩阵列和右端向量是同一种东西——都是"一次绕行对每条边的签到表",只不过列是三角形的签到表,右端是圈的签到表。方程 ∂C·x = z 逐行读就是:"选中的三角形们在这条边上的签到总和,必须等于圈在这条边上的签到"。

完整算例(正方形,对角线剖开):

      4 ←——— 3
      │    ↗ ↑        官方方向: [1,2]:1→2  [2,3]:2→3
      │ [1,3]│                 [1,3]:1→3  [3,4]:3→4
      ↓ ↗    │                 [1,4]:1→4
      1 ———→ 2

T₁ = [1,2,3],官方走法 1→2→3→1:走 1→2(顺 [1,2],+1)、走 2→3(顺 [2,3],+1)、走 3→1(逆 [1,3],−1)。
T₂ = [1,3,4],走法 1→3→4→1:1→3(顺,+1)、3→4(顺,+1)、4→1(逆 [1,4],−1)。
圈 z:沿 1→2→3→4→1 走:前三步全顺(+1,+1,+1),末步 4→1 逆 1,4,没碰对角线(0)。

全部数字摆开:

| 行(边) | T₁ 列 | T₂ 列 | 右端 z |
|--------|-------|-------|--------|
| [1,2]  | +1    | 0     | +1     |
| [2,3]  | +1    | 0     | +1     |
| [1,3]  | −1    | +1    | 0      |
| [3,4]  | 0     | +1    | +1     |
| [1,4]  | 0     | −1    | −1     |

每行代表一条表; 每列 T1, T2 代表一个 simplex 三角形; z 代表的是外边(大约就是同伦时的那个有待缩小的圈).

解 x₁ = x₂ = 1 逐行验证:对角线行 −1+1 = 0(两个三角形一个逆用它、一个顺用它——"相邻边抵消"就是这一行等于零);外圈四行各得 ±1,恰好是 z。未知数的含义也顺带清楚了:x₁ = 1 表示"T₁ 按官方走法用一次",若解出 −2 就是"反着用两次"。

最后一个减负说明:所有这些 ± 号只在 ℤ 系数时需要。取 ℤ/2 系数(TDA 页的做法)可以把方向约定整个扔掉——签到表只记"用没用过"(0/1),加法模 2,"抵消"退化成"同一条边被用了偶数次即消"。代价是看不见克莱因瓶那种挠;好处是连"发方向"这一步都省了。初学建 mental model,建议先在 ℤ/2 里想通(纯粹"数次数的奇偶"),再补 ± 号升级到 ℤ。
