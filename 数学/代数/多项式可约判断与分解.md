## 有理根定理 —— 原理:整除性

若既约分数 p/q 是 aₙxⁿ + ... + a₀ 的根,把它代入并通分,移项后立即得到:p 必须整除常数项 a₀,q 必须整除首项系数 aₙ。所以候选有理根只有有限个(a₀ 的因子 / aₙ 的因子的组合),逐个代入验证即可。本质上就是"分数根会在首尾两个系数上留下指纹"。

## Eisenstein —— 原理:mod p 后因子无处可藏

条件:某素数 p 整除除首项外的所有系数,但 p² 不整除常数项。关键一步:假设 f = g·h,两边 mod p,由条件得 f ≡ aₙxⁿ (mod p)。𝔽_p[x] 是唯一分解的,xⁿ 的因子只能是 x 的幂,所以 g 和 h 的常数项都必须被 p 整除——但这样 a₀ = g₀·h₀ 就被 p² 整除,与条件矛盾。一句话:让假想中的分解在 mod p 世界里自相矛盾。(更深的视角:条件强迫所有根的 p-adic 赋值都是 1/n,分母是 n 的斜率没法拆成两段整的——这就是 Newton 折线判据,Eisenstein 是它的特例。)

它的定位本来就不是"检测器",是构造器 + 理论引理。 但是它可以批量生产"保证不可约"的多项式, 可以证明一些经典多项式的不可约性, 比如分圆多项式 Φ_p(x) = x^(p−1) + ... + 1 的不可约性(直接看毫无 Eisenstein 形状,但做平移 x → x+1 后所有系数变成二项式系数,恰好全被 p 整除、常数项是 p——Eisenstein 瞬间点火。高斯当年费大劲的定理变成三行。这也顺便展示了它的隐藏技:f(x) 和 f(x+a) 同不可约,平移有时能救活它(虽然对随机多项式救活率依然很低))。

## mop p

1. Gauss 引理:f 在 ℚ 上可约 ⟹ f 在 ℤ 上就能分解成两个正次数的整系数因子(分母总能重新分配掉)。所以只需对付整数分解。
2. 约化是环同态:f = g·h 在 ℤ[x] 成立,两边 mod p 后 f̄ = ḡ·h̄ 依然成立。唯一要防的是"因子次数缩水"——只要 p 不整除 f 的首项系数,f̄ 次数不掉,ḡ、h̄ 也都还是正次数因子,f̄ 就可约。

逆否过来:f̄ 不可约 ⟹ f 在 ℚ 上不可约。 所以只要找到一个 p 就行. 

用法一(mod p,试 k 个素数):你要找的是一个"中奖"素数 p,使 f mod p 完全不可约。找到即拿到严格证明,立刻停。之所以要试多个,纯粹是因为每个素数只有约 1/n 的中奖率(10 次多项式 ≈ 0.1):Frobenius 在 Galois 群里"轮盘赌",只有转到 n-循环那一格,f mod p 才整块不碎。哪个素数会中事先算不出来,只能一个个开奖。

用法二(mod p,多素数拼图):就算没有任何一个素数单独中奖,每个素数的分解型也各给一条约束("真因子的次数必须是 {3,7} 的子集和"、"必须是 {5,5} 的子集和"……),几条约束的交集一旦为空,同样构成不可约的严格证明。这时多个 p 不是重复抽奖,而是每张都在收集拼图碎片,所以某次实测中平均 5.5 个素数就能结案,比等单素数中奖(11.8 个)快得多。

反过来注意一个不对称:如果 f 其实是可约的,那 mod p 永远不会给你任何"可约证书"——每个素数都碎、约束交集也一直非空,你只会一直等下去。所以实际算法不会无限试:试固定个数(比如几十个)后还没结案,就换赛道——要么直接 Hensel 提升 + 重组去真分解它(Zassenhaus/LLL),要么接受"大概率可约"的猜测去找因子。mod p 是抽奖找证书,LLL 是不靠运气把答案挖出来。

## LLL 多项式分解算法

LLL 能高效分解多项式. 它的思想和 PSLQ 有一些相同之处. 两者都基于**格基约化（Lattice Basis Reduction）**的核心思想：

| 共同点 | 说明 |
|--------|------|
| 都在格（Lattice）中寻找**短向量** | 利用格的几何结构 |
| 都能发现隐藏的**整数线性关系** | 找到满足条件的整系数组合 |
| 都是处理**近似数值**与**精确整数关系**的桥梁 | 数值→代数结构 |

关键区别

| 维度 | LLL | PSLQ |
|------|-----|------|
| **提出时间** | 1982（Lenstra, Lenstra, Lovász） | 1992（Ferguson & Bailey） |
| **核心任务** | 格基约化，输出一组**近似最短**的格基 | 专门寻找整数关系 $\sum a_i x_i = 0$ |
| **多项式分解** | ✅ 可高效分解整系数多项式（原始论文的主要应用之一） | ❌ 本身不直接用于多项式分解 |
| **数值稳定性** | 对浮点误差较敏感 | 专为高精度浮点环境设计，更稳定 |
| **理论基础** | Gram-Schmidt 正交化 + 格理论 | 基于矩阵迭代，与 LLL 有联系但独立发展 |
| **输出** | 约化后的**格基矩阵** | 一个具体的**整数关系向量** |


LLL 分解多项式（如 $f(x) ∈ mathbb{Z}[x]$）的完整流程:

**第一步：模 p 分解（先在有限域上把多项式分解）**

在 $\mathbb{F}ₚ[x]$ 中，用 **Berlekamp 算法**或 **Cantor-Zassenhaus 算法**分解：

$$f(x) ≡ \tilde{g}₁(x) ⋅ \tilde{g}₂(x) ⋯ \tilde{g}ₖ₍ₓ₎ \pmod{p}$$

> 有限域中的多项式分解**相对容易**，有高效的概率算法。

**第二步：Hensel 提升（模 $p$ → 模 $pᴺ$, 在更大mod数上, 也可以分解多项式）**

用 **Hensel 引理**，把模 p 的因子逐步提升到模 $pᴺ$（ $pᴺ$ 足够大）：

$$f(x) ≡ \hat{g}₁(x) ⋅ \hat{g}₂(x) ⋯ \pmod{pᴺ}$$

怎么选充分大的 N: 利用 Mignotte 界: 选 N 使 p^N > 2 M. 多项式的因式的系数的界 M 的 Mignotte公式: 给定 f(x) = aₙ xⁿ + ⋯ + a₀ ∈ Z[x], 它的任何因子 g(x) 的系数满足(其中：d 是 g(x) 的次数, $\|f\|_2 = √{a₀²+a₁²+⋯+aₙ^2}$ 是 $f(x)$ 系数的欧式范数, $(^d_i)=d!/(i!(d-i)!)$ )：

$$|gᵢ| ≤ (^d_i) \|f\|_2$$

而以上 N, 则是遍历 d, i 后取以上的最大值.

```
f(x) 已知
    │
    │  计算 ||f||₂ 和次数 n
    ▼
算出 Mignotte 界 M
    │
    │  选 N 使 p^N > 2M
    ▼
N 确定，可以开始 Hensel 提升
```

这一步是把有限域的信息"提升"到更精确的近似:
-  如果找到了某 Z_p 上不可约, 则原始多项式不可约, 可以不用继续. 但是 Z[x] 上不可约, Zp[x] 上有可能可约. 所以按前两步得到的因子, 只是说原多项式可能可约. 实际还需要做个除法来验证下.
- 我们本来在找原多项式的因子 $g(x)$, 这里找到的是 $\hat{g}(x)$, 其实后者已经是前者的近似了, $$\hat{g}(x) ≡g(x) \pmod{pᴺ}$$, 在 $pᴺ$ 足够大时，两者系数**几乎一样**. $\hat{g}(x)$ 是 $g(x)$ 的近似，LLL 的任务就是从这个近似里**还原出真正的** $g(x)$。为什么说近似: $$\mathbb{F}_p \xrightarrow{\text{Hensel 提升}} \mathbb{Z}/p^N\mathbb{Z} \xrightarrow{p^N \text{足够大}} \approx \mathbb{Z}$$

**第三步：构造格（关键！）**

> 格（Lattice）是什么: 给定 Rⁿ 中的一组线性无关向量 b₁, b₂, .., bₖ， 它们所有**整系数线性组合**构成的集合就是一个格(也就是实数向量, 整数系数; 也就是 lattice 是 R^n 里的一个固定的离散点集合)： L = { ∑ᵢ₌₁ᵏ nᵢbᵢ | nᵢ ∈ Z }
> 
> lattice 有base 概念, 换 base 后lattice 不变. 这个换 base, 指的是 lattice 约束下的换基. 格中的核心问题：最短向量(所有非零格点中哪个距离零点最近? 理论上遍历就行, 但是高维空间里, 距离 r 内点太多, 不具有可行性. 求这个最短向量是格密码学和 LLL 的核心, 乃 NP-hard 的. 

以一个候选因子 $\hat{g}(x)$（次数为 $d$）为例，构造格 $\mathcal{L}$：

寻找所有次数 ... 的整系数多项式 $h(x)$，满足：

$$\hat{g}(x) \mid h(x) \pmod{pᴺ}$$

这些 $h(x)$ 的系数向量构成一个**格**。

具体地，格基矩阵大致形如：

$$B = ...$$

**第四步：LLL 找短向量**

对这个格做 **LLL 约化**，找到**短向量** $\mathbf{v}$。

短向量对应的多项式 $g(x)$ 满足：
- 系数都是**整数**（在格中）
- 系数**绝对值小**（短向量保证）
- $\hat{g}(x) \mid g(x) \pmod{pᴺ}$

由 Mignotte 界（多项式系数的先验上界），**系数足够小的解必然就是真正的整系数因子**。

(以上: 格怎么构造, 为什么最短向量就是因子, 以后弄清补上). 

**直觉总结**

```
f(x) ∈ ℤ[x]
    │
    │  Berlekamp/Cantor-Zassenhaus
    ▼
𝔽_p[x] 中分解 ── 容易
    │
    │  Hensel 提升
    ▼
ℤ/p^N ℤ 中的近似因子
    │
    │  构造格 + LLL 找短向量
    ▼
ℤ[x] 中真正的因子 ── 目标
```

从 $\mathbb{Z}/p^N\mathbb{Z}$ 回到 $\mathbb{Z}$ 时，面临的问题是： “满足整除条件的多项式有**无穷多个**（差一个 $p^N$ 的倍式），哪一个才是真正的因子？” LLL 的作用就是在这无穷多个候选中，**找到系数最小的那个**——而那个就是答案。这正是"格中短向量"思想的精髓。
