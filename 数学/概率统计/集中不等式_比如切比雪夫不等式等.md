
# 集中不等式（concentration inequalities）-- 比如 比如切比雪夫不等式

它解决什么问题: 随便给一个分布——你什么都不知道，只知道它的均值和方差——能不能断定"跑得很远的概率不超过多少"？

答案是能。而且对任意分布都成立，不需要正态、不需要 n 很大、不需要任何假设。

这就是集中不等式。名字的来由：随机变量"集中"（concentrate）在均值附近，这些不等式给"能有多少概率跑到远处"设上界。

记号：Z = (X−μ)/σ 是标准化后的变量（E[Z]=0, Var[Z]=1），k=偏离几个 σ。

demo: https://superzhangmch.github.io/tiny_tools/demo/probability/concentration_inequalities.html

### Markov：一行就能证完

X ≥ 0 时：P(X≥a) ≤ (𝔼[X])/a

证明: 只需要一阶矩. 就是**扔掉一个非负积分的一部分**：

```
E[X] = ∫₀^∞ x dF  ≥  ∫ₐ^∞ x dF  ≥  a·∫ₐ^∞ dF  =  a·P(X≥a)
              ↑ 扔掉 [0,a) 那段      ↑ 把 x 都换成更小的 a
```

### Chebyshev：就是 Markov 用在平方上

P(|Z|≥k) ≤ 1/k²  ("3σ 之外概率不超过 1/9 = 11%"对任何分布都成立)

一行证明它: 只需要二阶矩: P(|X−μ| ≥ kσ) = P((X−μ)² ≥ k²σ²) ≤ E[(X−μ)²] / (k²σ²) = σ²/(k²σ²) = 1/k². 先两边平方, 再对 (X−μ)² 用 Markov
                 
但这个界很松。所以实践中它几乎不用来算具体概率。它的价值是"不用知道分布"。松不是证明写得差——界不能再改进. 所以"松"是「只知道 μ 和 σ²」这个前提的代价，不是证明不努力。任何只用二阶矩的公式都不可能写得更紧。松指的是:

```
界     P(|Z|≥2) ≤ 25%      ← 这句话对【任何分布】都成立, 永远不会错
真值   P(|Z|≥2) = 4.55%    ← 正态的实际值
松 5.5 倍                   ← "25%" 这个承诺, 比需要的宽松 5.5 倍
```

**Chebyshev 一用在均值上，就得到大数定律:**

n 个独立样本的均值：`Var[Z̄] = 1/n`。对 Z̄ 用一次 Chebyshev：P(|Z̄| ≥ ε) ≤ 1/nε²→0 (n→∞), 这就是弱大数定律的全部证明。但代价很明显——它是**幂律**衰减（斜率 −1），而真实的是**指数**衰减. 

### 单边：Cantelli

只问一边： P(Z ≥ k) ≤ 1/(1+k²)

一行证明它: 做法是 Chebyshev **加一个自由参数再优化**：对任意 s>0，P(Z ≥ k) ≤ P((Z+s)² ≥ (k+s)²) ≤ (1+s²)/(k+s)², 对 s 求最小 ⟹ s = 1/k ⟹ 得 1/(1+k²)

### 总结

| 不等式 | 式子 | 额外买了什么 | 紧度 |
|---|---|---|---|
| **Markov** | `E[X]/a` | 只要一阶矩 | 最松 |
| **Chebyshev** | `1/k²` | 二阶矩 | 松（幂律）|
| **Cantelli** | `1/(1+k²)` | 二阶矩 + 只问单边 | 略紧 |
| **Hoeffding** | `2e^(−2nε²/R²)` | **有界** | 指数 |
| **CLT** | `≈2Φ(−ε√n)` | **n→∞ 渐近** | 最紧，但**不是界，是近似** |

```
干什么   只知道均值方差, 就能断定"跑很远的概率 ≤ 多少", 对任意分布成立

Markov      P(X≥a) ≤ E[X]/a          扔掉非负积分的一部分, 一行
Chebyshev   P(|Z|≥k) ≤ 1/k²          Markov 用在 (X−μ)² 上, 一行
Cantelli    P(Z≥k) ≤ 1/(1+k²)        加自由参数再优化, 单边
大数定律     P(|Z̄|≥ε) ≤ 1/nε²        Chebyshev 用在均值上, 一行证完
Hoeffding   2e^(−2nε²/R²)            多买"有界", 幂律变指数

很松        正态 k=2 松 5.5 倍, k=4 松 4000 倍
但不可改进   三点分布精确取等号 ⟹ 松是"只知道二阶矩"的代价
想更紧       只能多买假设: 有界→Hoeffding, n→∞→CLT(但那是近似不是界)

小心        「双边折半当单边」1/(2k²) 是错的, 只对对称分布成立
```
