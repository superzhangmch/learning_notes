对一个根据某种表达式算出的高精度decimal, 如何找到这个原始表达式, 是 PSLQ 算法能做的事. 

PSLQ: 给定一组实数 $x_1, x_2, \dots, x_n$，找整数 $a_1, \dots, a_n$ 使得：

$$a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = 0$$

用它的时候, 先把你觉得可能要用到的部件(比如 sqrt(2), 3^{1/5}, log2, pi 等), 都提前算出来, 作为上面的 x_i. 然后让他找整数系数.

而 BBP 公式, 正式用它发现的. (BBP 公式可拆解成8个级数, 提前把8个 series 的前 n 项和算出(保证精度足够), 然后用 PSLQ 来拟合系数, 就得到了 BBP 公式). 现在大规模算 pi, 都是binary 上某种算法算, 算完后用 bbp 跳步检查尾数正确性(bin <=> hex 是零成本的), 没问题再把 binary => decimal. 

BBP: 

$$\pi = \sum_{k=0}^{\infty} \frac{1}{16^k} \left( \frac{4}{8k+1} - \frac{2}{8k+4} - \frac{1}{8k+5} - \frac{1}{8k+6} \right)$$

----

PSLQ 的核心能力是**在一堆实数里找隐藏的整数线性关系**，所以凡是"怀疑某个数满足某种代数/解析结构"的场景都能用。

### 1. 识别数学常数的封闭形式 (Closed Form)

最基础的用途。给你一个高精度小数，猜它是什么。

**例：** 算出某积分值 $= 2.0945514815...$，想知道它是什么。
构造候选部件：$\{1,\ \pi,\ \log 2,\ \sqrt{3},\ \pi^2,\ \pi\log 2, \dots\}$，PSLQ 可能告诉你：

$$3x - \pi\sqrt{3} = 0 \implies x = \frac{\pi\sqrt{3}}{3}$$

这类工作在实验数学 (Experimental Mathematics) 领域非常核心，Bailey & Borwein 写了整本书专门讲。

### 2. 发现代数数满足的最小多项式

如果某个数 $\alpha$ 是代数数，它满足某个整系数多项式 $a_n x^n + \cdots + a_0 = 0$。

**做法：** 构造 $x_i = \alpha^i$（$i = 0, 1, \dots, n$），PSLQ 找系数，就是最小多项式。

**例：** $\alpha = \sqrt{2} + \sqrt{3}$，高精度算出 $\alpha \approx 3.14626...$，
构造 $\{1,\ \alpha,\ \alpha^2,\ \alpha^3,\ \alpha^4\}$，PSLQ 给出 $\alpha^4 - 10\alpha^2 + 1 = 0$。

### 3. 数论 / 特殊函数的恒等式发现

猜测 L-函数、Zeta 函数、椭圆积分之间的关系。

**例：** Euler 发现 $\zeta(2) = \pi^2/6$，PSLQ 可以"重新发现"它：
高精度算出 $\zeta(2)$，构造 $\{1,\ \pi,\ \pi^2,\ \pi^3\}$，PSLQ 给出 $6\zeta(2) - \pi^2 = 0$。

类似地可以发现：
$$\zeta(4) = \frac{\pi^4}{90}, \quad \zeta(2)\zeta(3) = ?, \quad \text{各类 polylogarithm 恒等式}$$

### 4. 量子场论 / Feynman 积分的解析结果

这是 PSLQ 在物理里最重要的应用之一。

Feynman 图对应的积分极难解析计算，但数值积分相对容易。流程是：

```
高精度数值积分 Feynman diagram
        ↓
构造候选部件（ζ(3), ζ(5), π², ln2, ...）
        ↓
PSLQ 找整系数关系
        ↓
得到解析封闭形式，再反过来证明
```

Broadhurst 等人用这个方法发现了大量多圈 Feynman 积分的封闭形式。

### 5. 密码学 / 格密码中的应用

PSLQ 本质是在实数域上的**格基规约**问题（和 LLL 算法同族）。

- 可用于攻击某些基于格的密码方案
- 也用于分析 RSA 中的小指数问题
- 但这个方向用 LLL 更多，PSLQ 相对少见

### 6. 线性无关性的数值验证

反过来用：如果 PSLQ **找不到**整系数关系（在给定精度和系数界内），就为"这些数线性无关"提供数值证据。

**例：** 数值验证 $\{1,\ \pi,\ e,\ \pi e\}$ 之间不存在小系数的整数线性关系（虽然理论上仍未证明 $\pi + e$ 是否无理数）。

PSLQ 是"实验数学"的核心工具 —— 先数值计算，再用 PSLQ 猜结构，最后再去证明。
