## 中心极限定理

设 X₁, X₂, …, Xₙ 独立同分布，均值 μ，方差 σ² < ∞，令 $S_n = \frac{\sum_{i=1}^n X_i - n\mu}{\sigma\sqrt{n}}$, 则依分布 Sₙ → 𝒩(0,1), n → ∞

(不是所有分布, 都服从中心极限定理CLT(柯西分布, 很平滑的密度函数, 他就不服从CLT; 需要方差 σ² 存在))

### 基本知识

#### (1) 特征函数（Characteristic Function）

$φ_X(t) = 𝔼[e^{itX}] = ∫_{-∞}^{∞} eⁱᵗˣ f_X(x) dx$ 作为 f_X 的傅里叶变换, 是特征函数, 满足: 
- 唯一性: 分布由特征函数唯一确定： $φ_X = φ_Y ⇒ X = Y$
  * 特征函数本质上就是概率密度（或测度）的傅里叶变换, 傅里叶变换是单射(一一对应).
- 连续性定理（Lévy）: $φ_{Xₙ}(t) → φ_X(t)$ 逐点收敛 ⇒ 依分布收敛 Xₙ → X
  * 依分布收敛 Xₙ → X ⇔ $F_{Xₙ}(x) → F_X(x)$, 其中 F_x 是 CDF 分布函数.
  * Lévy 连续性定理的完整表述： $φ_{Xₙ}(t) → φ(t)$ 逐点，且 φ(t) 在 t=0 处连续 ⇒ 按分布收敛 Xₙ → X. 其中 φ 正好是某个 X 的特征函数。
- 独立性: X, Y 独立 ⇒ $φ_{X+Y}(t) = φ_X(t)⋅φ_Y(t)$
  * $φ_{X+Y}(t) = 𝔼[e^{it(X+Y)}] = 𝔼[e^{itX}⋅e^{itY}] = 𝔼[e^{itX}]⋅𝔼[e^{itY}] = φ_X(t)⋅φ_Y(t)$

| 性质 | 保证来源 | 一句话 |
|---|---|---|
| **唯一性** | 傅里叶变换的单射性 + 逆变换 | 频谱唯一决定信号 |
| **连续性** | 胎紧性 + 唯一性；关键是极限函数在 t=0 连续 | φ(t) 在0连续 = 概率没跑到无穷远 |
| **独立性** | 独立 ⇒ 𝔼[fg]=𝔼[f]𝔼[g]，直接计算 | 指数函数把加法变乘法 |

特征函数 $φ_X(t) = 𝔼[e^{itX}]$ 不是偶然选择，也不是唯一可能的形式，但它是在几个关键约束下最自然、最优的选择。

该特征函数能完整代表分布的所有信息. 不只是"能区分不同分布"，而是可以完全还原分布： $f_X(x) = (1/2π)∫_{-∞}^{∞} e⁻ⁱᵗˣφ_X(t) dt$. 

这个特征函数的自变量 t 代表的是频率. $φ_X(t) = 𝔼[e^{itX}]$ 是在问：分布 f_X 里，有多少"频率为 t 的成分"？
```
- t 很小（低频）：
    e^{itx} 变化慢，探测分布的整体形状
    → φ_X(t) 反映分布的大尺度结构
    → 均值、方差这些整体特征

t 很大（高频）：
    e^{itx} 变化快，探测分布的细节
    → φ_X(t) 反映分布的小尺度结构
    → 尾巴、局部峰值、不连续性
```
φ_X(t) 是用频率为 t 的振荡去"探测"分布，得到该频率成分的强度。扫过所有频率 t ∈ ℝ，就收集了分布的全部信息，可以无损还原。所以特征函数不只是区分分布的指纹，而是分布完整的等价表示。

#### (2). 不同的收敛

- 几乎必然收敛（a.s.）: P(limₙXₙ=X)=1，逐条样本路径收敛.
  - X 是随机变量, 乃样本空间Ω上的确定性函数X(ω), 随机来自ω. limₙXₙ=X 实际是说:对任意的ω 有, X₁(ω), X₂(ω), X₃(ω), … → X(ω)
  - P(limₙXₙ=X)=1 指的是 P({ω∈Ω:lim​ Xₙ(ω)=X(ω)}​​)=1, 也就是那些收敛的点的集合的总概率是1.
- 依概率收敛（convergence in probability）:对任意 ε > 0，都有 P(|Xₙ−X|>ε)→0，n→∞
  - P(|Xₙ−X|>ε) == P(|X_n(ω)-X(ω)|>ε) == P({ω∈Ω:|X_n(ω)-X(ω)|>ε}) 
- 依分布收敛（弱收敛）, 指的是CDF 分步函数列逐点的收敛 Fₙ(x) → F(x), ∀ x ∈ C(F), C(F)是F的连续点集合. F 的不连续点（间断点）的集合至多可数, 总概率是0
  - 而CLT 就这类收敛.
  - 依分布收敛不意味着对密度函数也有 fₙ(x) → f(x). 但是对正态分布来说这个是成立的.
  - 依分布收敛 = 只看分布的形状

上面三者: a.s.=> 依概率 => 依分布. 反之不行. (a.s.=>依概率很显然; 依概率 => 依分布: ..)

### 证明步骤

参: [clt_proof_fourier.html](https://superzhangmch.github.io/tiny_tools/demo/probability/clt_proof_fourier.html)

**Step 1：标准化**

不妨设 μ = 0, σ = 1（对 Yᵢ = (Xᵢ - μ)/σ 做替换），则 Sₙ = (1/√n)∑ᵢ₌₁ⁿ Yᵢ, 𝔼[Yᵢ]=0, 𝔼[Yᵢ²]=1

如图我们选这样一个指数分布(上图左; 它的特征函数如右图, 特征函数是value 是复数)

**Step 2：写出 Sₙ 的特征函数**

由独立性与特征函数的乘积性质：  $φ_{Sₙ}(t) = 𝔼[e^{itSₙ}] = 𝔼[e^{it/√n∑Yᵢ}] = ∏ᵢ₌₁ⁿ φ_{Yᵢ}(t/√n) = [φ_Y(t/√n)]ⁿ$
- 最后一个等号: $φ_{Yᵢ}(t/√n)$ == φ_Y(t/√n), 是因为所有 {Yᵢ} 独立同分布

<img width="2258" height="590" alt="image" src="https://github.com/user-attachments/assets/c14d92f2-5c28-4f16-96ad-3b8820714ad4" />

上述指数分布, 我们可以画出 Sₙ的特征函数(上图左), 并求逆, 得到 Sₙ 的密度函数(上图右). 按 CLT, Sₙ会趋近正态分布 N(0,I). 从图右看, n=10, 已经非常接近(如果试试其他分布, 会发现, n=10的时候往往比这个更接近 N(0,I)).

**Step 3：对原分布的特征函数做 Taylor 展开**

对原分布的特征函数(或者说是对 S₁)做 Taylor 展开: 在特征函数的 0 附近做展开 $e^{itX} = 1 + itX + (itX)²/2! + (itX)³/3! + ⋯$, 取期望 $φ_X(t) = 1 + it𝔼[X] - (t²/2)𝔼[X²] - (it³/6)𝔼[X³] + ⋯$

带入 𝔼[Y]=0, 𝔼[Y²]=1 有 $φ_Y(s) = 1 + is 𝔼[Y] - (s²/2)𝔼[Y²] + o(s²) = 1 - s²/2 + o(s²)$

令 s = t/√n，则：$φ_Y(t/√n) = 1 - t²/2n + o(1/n)$, 注意: 这是在复函数 φ_Y(.) 的零点周围的展开(看下图, 徐贤就是1-t²/2n). 

<img height="383" alt="image" src="https://github.com/user-attachments/assets/b7eea7b2-f55e-4840-9e34-4d6d0c92e7da" />

**Step 4：对 φ_Y(t/√n) 取 n 次幂并取极限**

$φ_{Sₙ}(t) = [1 - t²/2n + o(1/n)]ⁿ ⟶ e^{-t²/2}$, 根据 $lim_{n→∞}(1 + aₙ/n)ⁿ = eᵃ$（其中 aₙ → a）

如下图: 橙色的是 [1 - t²/2n]ⁿ, n足够大, 就可以把两条甩起来的压成近乎0, 而中间部分和正态是已经重合了.

<img height="342" alt="image" src="https://github.com/user-attachments/assets/f55eaabb-288c-4342-9395-8232c42dc403" />

**Step 5：识别极限分布**

$e^{-t²/2}$ 正是**标准正态分布** 𝒩(0,1) 的特征函数。由 Lévy 连续性定理，逐点收敛的特征函数对应分布弱收敛，故：Sₙ —d→ 𝒩(0,1) 

```
独立同分布假设
      │
      ▼
特征函数乘积：φ_{Sₙ}(t) = [φ_Y(t/√n)]ⁿ
      │
      ▼
Taylor 展开（用到 E[Y]=0, E[Y²]=1）
      │
      ▼
(1 - t²/2n + o(1/n))ⁿ ──→ e^{-t²/2}
      │
      ▼
Lévy 连续性定理
      │
      ▼
Sₙ →ᵈ N(0,1)
```

怎么理解正态分布
- 在所有满足 𝔼[X] = 0, 𝔼[X²] = σ² 的分布中，正态分布的熵最大。
