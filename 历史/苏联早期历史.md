**一、先分清三次触底**
- 1921 —— 内因，内战＋余粮收集制把农村抽干
- 1932 —— 内因，强制集体化＋征购，乌克兰大饥荒
- 1941 —— 外因，德国打进来

前两次是**同一个病发作两回**。1941 不是周期，是挨打。

**二、为什么是十年**
榨农村 → 榨干 → 饿死人 → 只好让步 → 缓过来 → 再榨。
关键是"缓过来"要多快：
- 耕畜被杀光，重新养起来要 5–8 年
- 人口损失恢复更慢，是跨代还的

所以节奏不是日历定的，是**人的身体定的**。大约十年。

**三、为什么能跌到 1 分**
计划体制没有价格信号。
市场：歉收 → 涨价 → 少征。
苏联：歉收 → 征购额还是政治局说了算 → 连种子粮一起收走。
1931 年乌克兰产量腰斩，征购要求基本没降。
最狠的一条：**1933 年饿死人的同时，还在往外卖粮食**（160 万吨）。
没有哪个环节会因为人快饿死而喊停。

**四、政策钟摆**
危机 → 让步 → 恢复 → 重新收紧 → 再危机。
1921 让步（NEP），1928 收紧；1934–36 缓和，1937 清洗。
一个来回约 8–12 年，正好和上面那个"恢复期"咬上。

**五、五年计划加了一把力**
每五年冲一次，两次冲刺叠出一次崩溃。
1928–32 冲 → 1932 谷底
1933–37 冲 → 1937 清洗

**六、1941 是借来的谷底**
1937 清洗杀掉了红军高层，1941 指挥体系是残的。
1932 饥荒毁掉的乌克兰和顿巴斯，正是德军主攻方向。
前面两刀，决定了这一刀有多深。

**七、但别真当成周期**
把 1938 也算上，就是 11 / 6 / 3 年，不整齐。
往前往后对不上（1905→1917 是 12 年，1932→1947 是 14 年）。

**一句话：**
不是宿命，是设计。
以农村当燃料、靠行政命令硬推工业化，就必然隔十来年反噬一次。

# 苏联这三十年（1917–1945）

**一句话：** 一个打出来的政权，靠榨农村养工业，中间反复崩，最后靠二战打成了超级大国。

---

**1917–1918｜十月革命**
- 1917年11月7日（俄历10月25日）布尔什维克攻下冬宫，夺权
- 特点：**不是全国革命，是首都政变**。政权只控制几个大城市，农村基本管不着

**1918–1921｜内战 + 战时共产主义**
- 白军、外国干涉军、各路势力一起打
- 经济上叫"战时共产主义"：余粮收集制，粮食直接抢走
- 特点：**用抢的方式支撑战争**。打完仗，农村也空了
- 1921年喀琅施塔得水兵叛乱、坦波夫农民起义，加上大饥荒 —— 政权自己先撑不住

**1921–1928｜新经济政策（NEP）**
- 1921年3月俄共十大：余粮收集制改成粮食税
- 允许小商小贩、私人小企业，货币改革发金卢布
- 列宁的说法："退一步，进两步"
- 特点：**喘气期**。经济恢复得很快，1925–26 年是这段的高点
- 1924年1月列宁去世 → 之后是权力斗争，斯大林逐步清掉对手

**1928–1932｜第一个五年计划 + 强制集体化**
- 1928年"大转折"，NEP 被废
- 目标：**十年内追上西方工业国**，钱从农村出
- 农民被赶进集体农庄，富农被"消灭"（大批流放）
- 特点：**工业数字猛涨，农村被抽干**
- 后果：1932–33 乌克兰大饥荒，哈萨克也死很多人

**1934–1936｜缓和期（表面繁荣）**
- 1934年取消配给制，1936年新宪法（纸面上很"民主"）
- 斯达汉诺夫运动，宣传劳动英雄
- 特点：**喘气，也是摆样子**。城市生活确实好转，农村还是苦

**1936–1938｜大清洗**
- 老布尔什维克、红军高层、普通干部被大批处决
- 图哈切夫斯基等一批元帅将军被杀
- 特点：**政权对自己人开刀**。军队指挥层被打空，为1941年埋雷

**1939–1941｜苏德条约 + 向西扩张**
- 1939年8月《苏德互不侵犯条约》，秘密议定书瓜分波兰
- 1939年9月打进波兰东部；1940年吞并波罗的海三国
- 1939–40 苏芬战争，打得很难看
- 特点：**和纳粹分赃，同时扩缓冲区**

**1941–1945｜卫国战争**
- 1941年6月22日德军入侵，开战几个月溃败几百万
- 1941–42 莫斯科保卫战；1942–43 斯大林格勒（转折点）
- 1943年库尔斯克；1944年反攻出国；1945年5月打进柏林
- 战时让步：恢复军衔、1943年恢复东正教、给将领放权
- 特点：**死伤最惨，但打出了一个超级大国**
- 代价：约2700万人死亡，西部国土被打烂

**1945｜战后**
- 占着东欧，成了和美国并列的两极
- 但也欠了一屁股债、农村又崩（1946–47年还有一次饥荒）

---

**串起来看**

| 时期 | 政权在干什么 | 老百姓感受 |
|---|---|---|
| 1918–21 | 打天下 | 抢粮、饿死 |
| 1921–28 | 退一步 | 缓过来了 |
| 1928–33 | 硬推工业化 | 农村被榨干 |
| 1934–36 | 歇一歇 | 好一点 |
| 1937–38 | 清自己人 | 谁都不敢说话 |
| 1941–45 | 拼命 | 死太多人 |

**规律就是：** 一紧就崩，崩了就让，让好了再紧。
三十年里，真正一直往上走的只有一样——**国家的工业实力和军力**。老百姓的日子，是拿这个换的。
