
## 群作用

**(1). 定义**

一个群 G **作用在**一个集合 X 上，是指一个映射： φ: G × X → X, (g, x) ↦ g ⋅ x.  要满足: 
- e ⋅ x = x
- (gh) ⋅ x = g ⋅ (h ⋅ x)

如此看, 群作用, 可以看作是群元素是一个算子, 作用于集合. 不过它需要每个元素(算子)是个可逆算子, 且是双射(群基本要求就能导出是双射).

注意: 群的单个元素作用于集合时, 是双射. 

**(2). Cayley 定理: 每个群都同构于一个置换群**

Cayley 定理: 对任意群 G，令它通过左乘作用在**自身**上：g⋅x = gx (x∈G), 则对应的群同态: $Φ: G → Sym(G), g ↦ σ_g$ 是一个单同态（injective; kernel=0），从而： G ≅ Φ(G) ≤ Sym(G)

它依赖于一点: 每个群元素作用于集合S, 乃是 S->S 的一个双射. 这里取 S=自身G. 从而是 Sym(G) 中元素. Sym(G)是G所有置换的群, |Sym(G)| = |G|!.

**(3). 几个经典例子**

- Sym 对称置换群作用在集合上（最基本）
- 旋转群作用在平面上
- 群作用在自身上（共轭作用）:G 作用在自身 X = G 上：g ⋅ x = gxg⁻¹
- 物理中的例子: 作用在量子态空间（自旋）上 / 晶体对称群作用在晶格上

**(4). 轨道-稳定子定理**

设 G 作用在 X 上，对 x ∈ X：
- 轨道 (Orbit): G⋅x = {g⋅x | g ∈ G} ⊆ X
  - 指的是: "x 能被变换到哪里去".
  - 轨道本质上反映了: X 中通过群作用, 能互相变换得来, 从而可以彼此沟通的集合. 反过来, 不同轨道之间永远无法沟通——无论你施加哪个群元素，都不可能从一个轨道跳到另一个轨道; 也就是有些元素pair, 无论如何, 没发通过群作用变成彼此。
    - 因此, Orbit定义了 X 上的等价关系: x∼y ⇔ ∃g∈G, 使得 g⋅x=y. 而等价关系能切分集合成独立子集, 因此不同轨道也是无交集的(只有重合成同一个的). 但是不同轨道长度不同, 但是都满足下面定理所说的, 轨道长度是|G|的因子.
- 稳定子 (Stabilizer群): Gₓ = {g∈G | g⋅x = x} ≤ G
  - "哪些群元素让 x 不动". 乃一个群.
  - 群的单个元素 g 作用于 X 时, 是双射, 所以 g 会对于某些x mapping前后不变, 而一个 x 会被某些 g 映射前后不变. 
- 轨道-稳定子定理: |G⋅x| × |Gₓ| = |G|. 注意: 不同x, 轨道大小不一.
  - 轨道大小 × 稳定子大小 = 群的阶

### 两个商空间:

(1). G/Gₓ（群/稳定子）--> 陪集空间, 轨道-稳定子定理

对 x ∈ X，定义等价关系“对x群作用一样, 则群元素等价”, 即 `g∼g' ⇔ g⋅x = g'⋅x ⇔ g⁻¹g' ∈ Gₓ`, 则有等价类 [g] = gGₓ 是陪集coset ([g] = {g' ∈ G | g'∼g} = {g'∈G | g⁻¹g' ∈ Gₓ} = {gh | h ∈ Gₓ} =: gGₓ; 注意用到 h=g⁻¹g')

=> G/Gₓ := {gGₓ | g∈G} => |G/Gₓ| = |G|/|Gₓ| (G 被 Gₓ 的陪集等分)

构造 mapping：φₓ: G/Gₓ → G⋅x, gGₓ ↦ g⋅x, 即陪集 -> 轨道中元素, 可以证明是双射, 从而每个 Gₓ 陪集对应一条 x轨道中元素. 所以 |轨道元素| == |陪集|, 有 |G⋅x| = |G/Gₓ| = |G|/|Gₓ|. 轨道-稳定子定理得证.
- φₓ well-defined: gGₓ==g'Gₓ, 则 g⋅x = g'⋅x
- 单射: 否则有 g, g' 不属同一个coset, 但g⋅x = g'⋅x; 而后者意味着g和g'属于同一个coset
- 满射: 易知

```
G = G_x  ⊔  g₁G_x  ⊔  g₂G_x  ⊔  g₃G_x      <---- cosets
  ↓φₓ       ↓φₓ         ↓φₓ       ↓φₓ
  x        g₁·x        g₂·x      g₃·x      <----- orbit
```

(2). X/G （集合/群作用）--> 轨道空间, Burnside 引理

定义等价关系: X中两个元素若能被G中元素作用而转化则等价, 即 `x∼y ⇔ ∃g∈G, g⋅x=y` => `X/G := {G⋅x | x∈X}`, 所得的等价类就是一个轨道. 

burnside 定理(轨道数量): $|X/G| = 1/|G| ∑_{g∈G} |Xᵍ|$, 其中 Xᵍ = {x ∈ X | g⋅x = x}
- 证明:
  - $∑_{g ∈ G} |Xᵍ| =拆散= |{(g,x) | g⋅x = x}| =按稳定子群组合= ∑_{x∈X} |Gₓ| = ∑_{x∈X} |G|/|G⋅x|$   (注意 |Gₓ|=|G|/|G⋅x|)
  - $∑_{x∈X} 1/|G⋅x| = ∑_(𝒪 ∈ 轨道空间X/G) (∑_{x ∈ 𝒪} 1/|𝒪|) = ∑_{𝒪 ∈ X/G} 1 = |X/G|$ (注意 $∑_{x∈𝒪} 1/|𝒪|=1$)
  - 于是: $∑_{g∈G}|Xᵍ| = |G| ∑_{x∈X} 1/|G⋅x| = |G|⋅|X/G|$

注意: $|X/G| = 1/|G| ∑_{g∈G} |Xᵍ| = |{(g,x) | g⋅x = x}|/|G|$, 这个theorem 要用的时候, 右侧需要把所有的 (g, x) 组合都算一遍. 那么本来轨道不就行了? 直接数轨道：需要判断哪些 x 等价，可能很复杂; 而数 |Xᵍ|，对每个 g，看有几个 x 不动, 要更简单.

更进一步还有 Pólya 计数定理. 乃 burnside 之升级.

### 应用:

(1). burnside 用来计数

一个正n变形, 有k种颜色来给顶点涂色, 有多少种涂法.

定义: 
- 集合 X = 所有涂法（正多边形不动，只是给顶点染色）
- 群 G = 旋转群（作用在涂法上）, 第 i 个元素: 旋转 i/n 个圆周
- g⋅x = 某个涂法旋转后, 看和哪个大涂法一样

那么, 一个轨道(X/G中元素)中的不同涂法, 是能被旋转(G中元素g)互转化的, 他们都是相同的涂法. 所以 X/G = 本质不同的涂法. 所以本问题就是看轨道数. 

用 burnside: |X/G| = 1/|G| ∑_{g∈G} |Xᵍ|, |G|=n, 对第j个群元素, 乃旋转 j/n个圆周, 记作 rʲ. 只需求出 |x^rʲ|, 且有 $|X^{rʲ}| = k^{gcd(j,n)}|$. 为啥:

$X^{rʲ}$ = 被 rʲ 固定不动的涂色方案 = {x ∈ X | rʲ⋅x = x}, 即旋转 rʲ 之后，涂色看起来一样。rʲ⋅x = x 意味着每个顶点 i 旋转后的颜色还是原来的颜色：即 x(i) = x(i - j (mod n)) ∀ 顶点i => 对 $X^{rʲ}$ 中的涂色, 顶点 i 和顶点 i-j 颜色必须相同。

从顶点 0 出发，每次跳 j 步(或者说转j/n个圆周)：0 → j → 2j → 3j → ⋯ (mod n), 回到 0 的最小次数m是多少哦? 需要 mj ≡ 0 (mod n)，故 m = n/gcd(j,n). 所以从 0 出发的循环是： {0, j, 2j, …, j(n/gcd(j,n)-1)}, 它们颜色必须相同。对 rʲ, 这样的0 → j → 2j → 3j..循环, 共有 gcd(j,n) 个, 每个顶点的循环可以从 k 种颜色中任选一种, 总种数是 $k^{gcd(j,n)}$.

(2). 轨道-稳定子定理

|G⋅x| × |Gₓ| = |G|, 用它推算群大小. 比如对正方体旋转群(一个正方体, 各种旋转后, 看上去仿佛没变的操作构成的群, 有24个元素; 由绕x/y/z轴的旋转, 绕着对角过心轴的旋转, 绕着过对边中点且过心的轴的旋转三类组成). 看: https://superzhangmch.github.io/tiny_tools/demo/algebra/cube_rotation_group_3d.html  

- X = {A, B, C, D, E, F}：立方体 6个面，每个面贴一个标签，无论怎么转标签不变。
- G = 所有旋转操作的集合。
- g⋅A = B：旋转 g 之后，A 面跑到了 B 面原来所在的位置。

对于面 A:
- 它通过各种旋转，能跑到所有6个位置, 所以它的轨道 |G⋅A| = 6
- 稳定子 $G_A = {g ∈ G | g⋅A = A}$, 对于面A, 能做到这样的必须是绕着垂直于A的直线的旋转, 所以共有 0°, 90°, 180°, 270° 四种 => $|G_A| = 4$

=> |G| = |G⋅x| × |Gₓ| = 6 × 4 = 24

## 群（Group）是对**对称性**的抽象

(1). 对称

群论本质上是对**对称性**和**变换**的数学抽象。

核心直觉：可逆变换的复合. 群抽象的是一类"**操作/变换**"的共同结构，这些操作满足：

| 直觉来源 | 举例 |
|---|---|
| 几何图形的对称操作 | 正三角形的旋转、翻转 |
| 数的加减运算 | 整数加法 |
| 魔方的还原步骤 | 每一步操作及其逆操作 |
| 物理系统的对称性 | 晶体结构、粒子物理 |

**四条公理的直觉含义**

群 (G, ⋅) 满足四条公理，每条都对应一个直觉：

1. **封闭性**：两个操作组合后，结果仍是合法操作
2. **结合律**：操作的顺序组合方式不影响最终结果
3. **单位元**：存在"什么都不做"的操作（恒等变换）
4. **逆元**：每个操作都可以被"撤销"（可逆性）

**为什么说是"对称性"的抽象？**

> **对称性** = 某种变换下保持不变的性质

- 正方形在旋转90°后"看起来一样" → 旋转构成群
- 物理规律在时间平移下不变 → 时间平移群（→ 能量守恒，诺特定理）
- 方程的根在某些置换下不变 → 置换群（→ 伽罗瓦理论）

(2). 对称性与群作用

**群作用（Group Action）** 确实可以说是群"第一存在价值"，理由就藏在群的起源里：群的**定义**是一组公理（封闭、结合、单位元、逆元）, 但群的**意义**在于——它**作用在某个对象上**

群的所谓对称本性, 是通过群作用体现的. 说他对称, 就是因为群作用前后, 被他所用的东西并没变(还是那个东西, 只是换了下姿势而已). 群作(G⋅X)之对称, 是关于 X 集合整体, 而不是单个或部分元素. 对于图形的旋转群之对称, 算最好诠释, 可看 https://superzhangmch.github.io/tiny_tools/demo/algebra/cube_rotation_group_3d.html  

一个"悬空的群"，只是一个抽象代数结构。只有当它**作用在某个集合/空间上**，对称性才真正显现出来。

**群作用是群的"本体论"**

可以这样理解这个层次关系：

```
对称现象（旋转、翻转、置换……）
        ↓ 抽象
    群（捕捉结构）
        ↓ 实现
    群作用（回到具体对象上）
```

群先从具体的作用中被**抽象**出来， 然后又通过群作用**回归**到具体对象上——这个"离开现实 → 回到现实"的循环，正是群论强大的原因。

凯莱定理(见上文)暗示, 每一个群(无论有限还是无限群)都同构于某个置换群. 这个定理几乎在说：**群天生就是用来作用的**。一个抽象的群，本质上就是某个集合上的一组置换——群作用不是群的"附加功能"，而是群的**本质身份**。
