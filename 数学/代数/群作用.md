
## 群（Group）是对**对称性**的抽象

群论本质上是对**对称性**和**变换**的数学抽象。

核心直觉：可逆变换的复合. 群抽象的是一类"**操作/变换**"的共同结构，这些操作满足：

| 直觉来源 | 举例 |
|---|---|
| 几何图形的对称操作 | 正三角形的旋转、翻转 |
| 数的加减运算 | 整数加法 |
| 魔方的还原步骤 | 每一步操作及其逆操作 |
| 物理系统的对称性 | 晶体结构、粒子物理 |

**四条公理的直觉含义**

群 (G, ⋅) 满足四条公理，每条都对应一个直觉：

1. **封闭性**：两个操作组合后，结果仍是合法操作
2. **结合律**：操作的顺序组合方式不影响最终结果
3. **单位元**：存在"什么都不做"的操作（恒等变换）
4. **逆元**：每个操作都可以被"撤销"（可逆性）

**为什么说是"对称性"的抽象？**

> **对称性** = 某种变换下保持不变的性质

- 正方形在旋转90°后"看起来一样" → 旋转构成群
- 物理规律在时间平移下不变 → 时间平移群（→ 能量守恒，诺特定理）
- 方程的根在某些置换下不变 → 置换群（→ 伽罗瓦理论）

## 群作用知识

**(1). 定义**

一个群 G **作用在**一个集合 X 上，是指一个映射： φ: G × X → X, (g, x) ↦ g ⋅ x.  要满足: 
- e ⋅ x = x
- (gh) ⋅ x = g ⋅ (h ⋅ x)

如此看, 群作用, 可以看作是群元素是一个算子, 作用于集合. 不过它需要每个元素(算子)是个可逆算子, 且是双射(群基本要求就能导出是双射).

**(2). Cayley 定理: 每个群都同构于一个置换群**

Cayley 定理: 对任意群 G，令它通过左乘作用在**自身**上：g⋅x = gx (x∈G), 则对应的群同态: $Φ: G → Sym(G), g ↦ σ_g$ 是一个单同态（injective; kernel=0），从而： G ≅ Φ(G) ≤ Sym(G)

它依赖于一点: 每个群元素作用于集合S, 乃是 S->S 的一个双射. 这里取 S=自身G. 从而是 Sym(G) 中元素. Sym(G)是G所有置换的群, |Sym(G)| = |G|!.

**(3). 几个经典例子**

- Sym 对称置换群作用在集合上（最基本）
- 旋转群作用在平面上
- 群作用在自身上（共轭作用）:G 作用在自身 X = G 上：g ⋅ x = gxg⁻¹
- 物理中的例子: 作用在量子态空间（自旋）上 / 晶体对称群作用在晶格上

**(4). 轨道-稳定子定理**

设 G 作用在 X 上，对 x ∈ X：
- 轨道 (Orbit): G⋅x = {g⋅x | g ∈ G} ⊆ X
  - 指的是: "x 能被变换到哪里去".
  - 轨道本质上反映了: X 中通过群作用, 能互相变换得来, 从而可以彼此沟通的集合. 反过来, 不同轨道之间永远无法沟通——无论你施加哪个群元素，都不可能从一个轨道跳到另一个轨道; 也就是有些元素pair, 无论如何, 没发通过群作用变成彼此。
    - 因此, Orbit定义了 X 上的等价关系: x∼y ⇔ ∃g∈G, 使得 g⋅x=y. 而等价关系能切分集合成独立子集, 因此不同轨道也是无交集的(只有重合成同一个的). 但是不同轨道长度不同, 但是都满足下面定理所说的, 轨道长度是|G|的因子.
- 稳定子 (Stabilizer群): Gₓ = {g∈G | g⋅x = x} ≤ G
  - "哪些群元素让 x 不动". 乃一个群.
- 轨道-稳定子定理: |G⋅x| × |Gₓ| = |G|
  - 轨道大小 × 稳定子大小 = 群的阶

### 两个商空间:

(1). G/Gₓ（群/稳定子）--> 陪集空间

固定一个 x ∈ X，在 G 上定义等价关系：`g∼g' ⇔ g⁻¹g' ∈ Gₓ ⇔ g⋅x = g'⋅x`, 

则每个等价类 [g] = {g' ∈ G | g'∼g} = {g'∈G | g⁻¹g' ∈ Gₓ} = {gh | h ∈ Gₓ} =: gGₓ; 注意用到 h=g⁻¹g'

=> G/Gₓ := {gGₓ | g∈G} => |G/Gₓ| = |G|/|Gₓ| (G 被 Gₓ 的陪集等分)

然后可以导出轨道-稳定子定理: 只需要构造双射 G/Gₓ ⟷ G⋅x. 定义映射：φₓ: G/Gₓ → G⋅x, gGₓ ↦ g⋅x
- well-defined(不会多value): g' ∈ gGₓ ⇒ g' = gh for some h∈Gₓ ⇒ g'⋅x = gh⋅x = g⋅(h⋅x) = g ⋅ x
- 单射: φₓ(gGₓ) = φ(g'Gₓ) ⇒ g ⋅ x = g' ⋅ x ⇒ g⁻¹g' ∈ Gₓ ⇒ gGₓ = g'Gₓ
- 满射: 轨道中任意点形如 g⋅x，它就是 φₓ(gGₓ) 的像

φₓ 是双射，所以：|G⋅x| = |G/Gₓ| = |G|/|Gₓ|

(2). X/G （集合/群作用）--> 轨道空间

在被作用集合X上可以定义等价关系：`x∼y ⇔ ∃g∈G, g⋅x=y` => `X/G := {G⋅x | x∈X}`

```
X 的元素：   ● ● ● ■ ■ ▲ ▲ ▲
              ↓    ↓   ↓ 商掉群作用
X/G 的元素：  {●}  {■}  {▲}
```

把所有"本质相同"(可以通过G中元素互相转化)的元素捏成一个点。

(3). 两者的关系

gx = g'x ⟺ g, g' 在同一个 Gₓ 的陪集里

存在**自然双射**：G/Gₓ ⟷ G⋅x; gGₓ ⟼ g⋅x; 所以：单个轨道 ≅ G/Gₓ

```
群 G 按稳定子分成陪集：

G = G_x  ⊔  g₁G_x  ⊔  g₂G_x  ⊔  g₃G_x
  ↓          ↓           ↓           ↓
  x        g₁·x        g₂·x        g₃·x

每个陪集 ──对应──▶ 轨道中的一个点
```

> **"商掉稳定子"** = 把G中"做同样事情"的元素粘合 = 恰好得到一条轨道

完整的层次结构

```
G 作用在 X 上
        │
        ▼
X 被分解为轨道（轨道空间 X/G）
        │
        │  聚焦单条轨道 G·x
        ▼
单条轨道 ≅ G/G_x    （陪集空间）
        │
        │  用 Lagrange 定理
        ▼
|G·x| × |G_x| = |G|  （轨道-稳定子定理）
```

## 核心直觉总结

> **为什么是"商掉稳定子"？**

因为稳定子 Gₓ 里的元素**对 x 什么都不做**，是"冗余的对称性"。

把这些冗余商掉之后，G 中剩余的自由度**恰好一一对应轨道中的点**。

G      /     Gₓ      =    G ⋅ x
    ╰╯           ╰╯           ╰───╯
所有对称性   不动x的冗余   真正的自由度

## other

**群作用（Group Action）** 确实可以说是群"第一存在价值"，理由就藏在群的起源里：群的**定义**是一组公理（封闭、结合、单位元、逆元）, 但群的**意义**在于——它**作用在某个对象上**

一个"悬空的群"，只是一个抽象代数结构。只有当它**作用在某个集合/空间上**，对称性才真正显现出来。

**群作用是群的"本体论"**

可以这样理解这个层次关系：

```
对称现象（旋转、翻转、置换……）
        ↓ 抽象
    群（捕捉结构）
        ↓ 实现
    群作用（回到具体对象上）
```

群先从具体的作用中被**抽象**出来， 然后又通过群作用**回归**到具体对象上——这个"离开现实 → 回到现实"的循环，正是群论强大的原因。

凯莱定理(见上文)暗示, 每一个群(无论有限还是无限群)都同构于某个置换群. 这个定理几乎在说：**群天生就是用来作用的**。一个抽象的群，本质上就是某个集合上的一组置换——群作用不是群的"附加功能"，而是群的**本质身份**。
