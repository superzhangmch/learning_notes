### 复变解析函数的神奇性质

| # | 性质 | 简述 |
|---|------|------|
| 1 | **保角性（共形映射）** | 解析函数保持曲线交角与方向 |
| 2 | **积分路径无关** | 解析区域内曲线积分只依赖端点 |
| 3 | **最大模原理** | 模的最大值只能在边界取到 |
| 4 | **边界决定内部（Cauchy积分公式）** | 边界值完全确定内部所有值及导数 |
| 5 | **无穷可微（解析性）** | 一阶可微 ⟹ 无穷阶可微 |
| 6 | **零点孤立性** | 零点不能聚集，除非恒为零 |
| 7 | **唯一延拓性** | 一小块区域的值决定整个连通域的值 |
| 8 | **调和性** | 实部虚部均满足拉普拉斯方程 Δu = 0 |
| 9 | **刘维尔定理** | 有界整函数必为常数 |
| 10 | **平均值性质** | 函数值等于任意圆周上的平均值 |
| 11 | **开映射定理** | 非常数解析函数将开集映射为开集 |
| 12 | **幂级数展开** | 解析函数在收敛圆盘内等于其Taylor级数 |
| 13 | **辐角原理** | 边界像曲线绕原点的圈数等于区域内零点数减极点数 |

### 背后思想脉络: 主线：C-R方程是一切的根源

复可微的定义要求极限： $f'(z) = lim_{Δz → 0} (f(z+Δz)-f(z))/Δz$, 从任意方向趋近结果必须相同. 写成 f = u + iv，有 ∂u/∂x = ∂v/∂y, ∂u/∂y = -(∂v/∂x), 即 Cauchy-Riemann 方程.

(1). 为什么保角

u, v 的实可微本来就意味着局部线性变换（2×2 矩阵），而 C-R 方程要求这个矩阵形如：

| a, -b |
| b, a |

这正好是**旋转 + 缩放**的矩阵, 于是: 复可微 ⟺ 局部变换 = 旋转 × 缩放, 保角(旋转与缩放都保角)

(2). C-R => 椭圆型PDE

f: ℝ² → ℝ² 有**4个偏导数**自由度。C-R方程加上**2个约束**，自由度减半。C-R方程就是一个**椭圆型偏微分方程系统**。解析 ⟺ 满足椭圆型PDE ⟺ "无限刚性"

“椭圆型方程的解不允许"局部自由", 则:

| 约束表现 | 对应性质 |
|---------|---------|
| 不能有内部极值 | 最大模原理 |
| 边界完全控制内部 | Cauchy公式 |
| 局部决定全局 | 唯一延拓 |
| 自动正则 | 无穷可微 |

(3). 积分路径无关

> 格林公式: (建立了**平面区域上的二重积分**与其**边界曲线上的曲线积分**之间的联系) 设 D 是平面上的**有界闭区域**，其边界 ∂D 是**分段光滑的曲线**，P(x,y)、Q(x,y) 在 D 上具有**连续的一阶偏导数**，则： $∮_{∂D} P dx + Q dy = ∬_D ((∂Q/∂x) - (∂P/∂y)) dA$. 其中 ∂D 取**正方向**（逆时针方向），即区域 D 始终在行进方向的**左侧**。

而 C-R 中的 ∂u/∂x = ∂v/∂y, 预示着根据 Green 公式, 复积分(乃线积分)是路径无关的. 有洞时, 曲线上积分!=0, 因为不满足 green 公式中说的 D 有一阶连续导条件.

(4). Cauchy 积分公式 => 平均值定理 => 最大模原理

> Cauchy 积分公式: 若 f 在区域 D 内解析，C ⊂ D 是简单闭曲线，z₀ 在 C 内部，则： $f(z₀) = (1/2π i) ∮_C (f(z)/(z - z₀)) dz$

上式把 C 取为圆周, 即可得平均值定理: 在圆心的值 = 圆周上函数值的平均. 或者说: 设 f(z) 在圆盘 |z - z₀| ≤ r 上解析，则： f(z₀) = (1/2π) ∫₀^{2π} f(z₀ + reⁱᶿ) dθ}

**平均值定理 => 最大模原理: **

> 最大模原理: 解析函数f在一个有界区域内的最大模, 一定在边界上. 如果没有零点, 则最小模也在边界上(这时考虑 1/f 即得).它意味着，一条简单封闭曲线内部，如果没零点与极点，则 ｜f｜
是某种坡面或鞍面或二者的组合.如果有一个零点无极点，则是下凹一个坑。下凹的坑只会出现在零点处。

设 |f(z)| 在内部某点 z₀ ∈ D 取到最大值 M = |f(z₀)|。取足够小的 r，使圆盘 |z - z₀| ≤ r 完全在 D 内。

则 $M = |f(z₀)| = |(1/2π) ∫₀^{2π} f(z₀ + reⁱᶿ) dθ| ≤ (1/2π) ∫₀^{2π} |f(z₀ + reⁱᶿ)| dθ ≤ (1/2π) ∫₀^{2π} M dθ = M$

=> $(1/2π) ∫₀^{2π} |f(z₀ + reⁱᶿ)| dθ = M$ => |f(z₀ + reⁱᶿ)| = M 对所有 θ ∈ 0~2π => 圆周上模处处等于 M。

另证: 假设 z0 是一个内部最小module 点, 在 z0 处展开: f(z0 + ε) = f(z0) + cₖ · εᵏ + O(εᵏ⁺¹), 其中 cₖ 是展开后第一个非零系数 (若所有系数为零则 f 为常数). f(z0 + ε) = f(z0) · (1 + cₖ/f(z0) · εᵏ + O(εᵏ⁺¹)) => |f(z0 + ε)| = |f(z0)| · |1 + cₖ /f(z0) · εᵏ + O(εᵏ⁺¹)|, 可以证明可以在小领域内选取某个小 ε, 使得 cₖ/f(z0)·εᵏ 为负. 于是 |f(z0 + ε)| < |f(z0)|, 矛盾.

(5). 刘维尔定理: 有界整函数必为常数

> 整函数: 在整个 C 上解析的函数(不包括 ∞). 从 series expanding 角度, 则是: 它在任意点 c 都可以 Taylor 展开，而且收敛半径是无穷大： f(z) = a₀ + a₁(z-c) + a₂(z-c)² + ...

注意, 最大模原理不能直接推导出它. 对非常数函数: (1). 多项式函数f属于整函数, 且满足 |f(z)| → ∞, when z → ∞. (2). 一般性的整函数的tailor series 是无穷多项, 这样|f(z)| → ∞ 不再天然成立. 而刘维尔定理是说, 至少存在 |zᵢ| → ∞, 使得 |f(zᵢ)| → ∞.

证明: 对整函数, 在以 z₀ 为圆心、R 为半径的圆 $C_R$，用导数公式：$f'(z₀) = (1/2π i) ∮_{C_R} (f(z)/((z-z₀)²)) dz$ => |f'(z₀)| ≤ (M/R), 其中M是半径R内的界. 如果 f 全局有界, 则 R -> ∞, 有 |f'(z₀)| ≤ (M/R) -> M/∞=0 => |f'(z₀)| = 0. 由 z₀ 的任意性, f == constant.

(6). series expanding

- Taylor series:  f(z) = a0 + a1(z-c) + a2(z-c)² + ..., 它的收敛区域一定是一个圆盘, 半径由由距离展开中心 c 最近的奇点决定。无奇点, 则半径是 ∞. 如果 f 是整函数，，那么它在任意点 c 都可以 Taylor 展开，而且收敛半径是无穷大：
- Laurent series: f(z) = ... + a₋₂(z-c)⁻² + a₋₁(z-c)⁻¹ + a0 + a1(z-c) + a2(z-c)² + ..., 它的收敛区域一般不是圆盘，而是一个环形区域：r < |z-c| < R. c 是f一个极点, 如果f 有多个极点, 那就看你想用哪个, 而 R 乃到最近的别的的极点距离.

一个解析函数的任意一点, 都在它的临近的开集上, 有tailor/laurent 展开. 但是这展开, 并不一定是全局有效的. 也就是说, 存在这样的区域: 两个不同的展开, 在它上面, 任意点的value 都一样. 为啥这样: 这就仿佛两个多项式中的一个可以整理变成另一个! 无穷项series 一般不满足这样的重新整理. 但是解析函数的幂级数，在收敛圆盘内部绝对/一致收敛，所以可以合法地“重新展开”，把一个 Taylor series 变成另一个中心的 Taylor series。

(7). 辐角原理

f(z) 沿封闭曲线 C 的辐角总变化量 = 2π × (N - P), 其中 N = C 内部零点个数，P = C 内部极点个数. 按对于重合的零点或极点, 都要阶数计算. 用公式则是: (1 / 2πi) ∮C f'(z) / f(z) dz = N - P

为什么 f'(z) / f(z)? 
- 展开看:
  - 如果 z = a 是 f 的 m 阶零点，那么改写: f(z) = (z - a)ᵐ × g(z) => f'(z) / f(z) = m / (z - a) + g'(z) / g(z) => res(f'/f) = m 
  - 如果 z = b 是 f 的 n 阶极点，那么改写: f(z) = h(z) / (z - b)ⁿ => f'(z) / f(z) = -n / (z - b) + h'(z) / h(z) => res(f'/f) = -n
  - 因此把 f'(z)/f(z) 沿 C 积分，就等于所有这些留数的总和 = 零点阶数总和 - 极点阶数总和
- log f 角度:
  - f'/f=(log f)' => ∫_c (f'/f) dz = ∫_c (log f)' dz = log f, 所以 ∫_c (f'/f) dz 描述的是沿曲线一圈时 log f(z) 的变化。
  - log f(z)=ln |f(z)|+iarg f(z) 是多叶的, 闭曲线走完后，ln |f(z)| 回到原值，主要变化来自辐角：∫_c (f'/f) dz = i Δ_c arg f(z), 而 Δ_Γ arg f(z)=2π(N-P).
    - 为什么 Δ_C arg f = 2π(N - P): 仍然需要回到 f(z) = (z-a)ᵐ⋅g(z), f(z) = h(z)/(z-b)ⁿ 分解后看.

## 代数基本定理的证明

1. 基于: 刘维尔定理/最大模原理

假设无零点, 则考虑 1/f(z), 它在 C 上解析, 且 |1/f(z)|→0 when z→∞. 由: 刘维尔定理, 1/z==constant, 由最大模定理, 最大模出现在边上→0. 都导致矛盾.

背后直觉: 没有零点的联通解析区域, 不会有凹陷. |f(z)|→∞当z→∞在, 这意味着大尺度上, |f(z)| 有凹陷, 与 |f(z)| 没零点则无凹陷矛盾.

2. 基于: 辐角定理

f(z)≈aₙzⁿ 当 z 充分大. 于是 f(z) 在充分大的圆周上的随z走一圈的辐角应该是 2nπ, 而同时 ∫_c f'/f dz = 0(f无零点, 则f'/f处处解析, 于是积分是0) 而非 i 2nπ, 矛盾.

3. 高斯的几何证明

对 f 按 z = x+iy 分解成 real(f) + img(f), 分别看 real = 0 和 img = 0 曲面的零曲线. 在充分大圆环上, 每条零曲线和这个圆有两个交点, 来自 real 和 img 的相邻曲线的交点交替出现(也就是 r1, i1, r2, i2, r3, i3, r4, i4, .. 这样. 其中 r-N, r-{N+1} 是 real 的曲线, i-N, i-{N+1} 是 img 的曲线), 于是这两条曲线必然有交点 - 即 f 的零点.

## 知识点

### 1. 柯西定理

**柯西定理（Cauchy's Integral Theorem）:** 设 f(z) 在单连通区域 D 内**解析**，C 是 D 内任意一条**简单闭合曲线**，则： $∮_C f(z) dz = 0$

**柯西积分公式:**:  若 f(z) 在区域 D 内解析， z₀ 是 D 内一点，C 是包围 z₀ 的正向简单闭合曲线，则： $f(z₀) = (1/2π i) ∮_C (f(z)/(z - z₀)) dz$

更一般地，对高阶导数： $f⁽ⁿ⁾(z₀) = (n!/2π i) ∮_C (f(z)/((z - z₀)ⁿ⁺¹)) dz$

### 2. 留数定理（Residue Theorem）

设 f(z) 在区域 D 内除有限个**孤立奇点** z₁, z₂, .., zₙ 外解析，C 是 D 内包围所有这些奇点的正向简单闭合曲线，则： $∮_C f(z) dz = 2π i ∑ₖ₌₁ⁿ Res[f, zₖ]$

留数的定义: f(z) 在孤立奇点 zₖ 处的留数，是其 **Laurent 展开**中 (z - zₖ)⁻¹ 项的系数 a₋₁： Res[f, zₖ] = a₋₁
